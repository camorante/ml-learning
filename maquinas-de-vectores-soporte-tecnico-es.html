§6 · Práctica

Lo que hay que saber para usarla

  • Escalar siempre. RBF y el término dependen de las distancias: StandardScaler dentro de un Pipeline.
  • Buscar C y γ en escala logarítmica (por ejemplo ) con validación cruzada. gamma="scale" usa , un buen punto de partida.
  • Probabilidades: probability=True ajusta una sigmoide sobre (Platt) con validación cruzada interna: 5 veces más lento, y predict_proba puede no coincidir con predict. Si necesitas probabilidades bien calibradas, mejor CalibratedClassifierCV o una logística.
  • Clases desbalanceadas: class_weight="balanced" usa un distinto por clase.
  • Multiclase: SVC entrena uno contra uno ( modelos); LinearSVC, uno contra el resto.
  • Datos grandes: LinearSVC (liblinear) o SGDClassifier(loss="hinge"); para no linealidad, Nystroem o RBFSampler (características aleatorias de Fourier) más un modelo lineal.
  • Variantes: SVR (pérdida -insensible para regresión) y One-Class SVM (frontera de la clase normal, para anomalías).

§7 · Implementación

SVM con SMO desde cero

mysvm.py · comparado con sklearn.svm.SVC(shrinking=False) en lunas, círculos y nubes gaussianas, con kernel lineal y RBF: mismos vectores soporte; decision_function igual hasta 10⁻⁶ (10⁻⁴ con C = 100, γ = 3). La diferencia es de convergencia: con tol = 10⁻¹¹ nuestra solución cumple KKT a 10⁻¹¹ y la de libsvm se queda en 10⁻⁷–10⁻⁵, con el mismo valor del dual en 11 cifras

import numpy as np

def rbf(A, B, gamma):
    d2 = (A**2).sum(1)[:, None] + (B**2).sum(1)[None, :] - 2 * A @ B.T
    return np.exp(-gamma * np.maximum(d2, 0))

class SVM:
    """SVM de margen blando resuelta por SMO (mismo esquema que libsvm, sin 'shrinking')."""
    def __init__(self, C=1.0, kernel="rbf", gamma=1.0, tol=1e-3, max_iter=100_000):
        self.C, self.kernel, self.gamma, self.tol, self.max_iter = C, kernel, gamma, tol, max_iter

    def K(self, A, B):
        return A @ B.T if self.kernel == "linear" else rbf(A, B, self.gamma)

    def fit(self, X, y):                      # y en {-1, +1}
        n, C = len(X), self.C
        K = self.K(X, X)
        a = np.zeros(n)                       # multiplicadores α
        G = -np.ones(n)                       # gradiente del dual: Qα - 1
        for it in range(self.max_iter):
            yG = -y * G
            up  = ((y > 0) & (a < C)) | ((y < 0) & (a > 0))   # pueden subir en la dirección y
            low = ((y > 0) & (a > 0)) | ((y < 0) & (a < C))   # pueden bajar
            i = np.where(up)[0][yG[up].argmax()]
            Gmax, Gmin = yG[i], yG[low].min()
            if Gmax - Gmin < self.tol:        # condiciones KKT cumplidas: fin
                break
            # segundo índice: el que más baja el objetivo (aprox. de 2º orden)
            cand = np.where(low & (yG < Gmax))[0]
            q = np.maximum(K[i, i] + K[cand, cand] - 2 * K[i, cand], 1e-12)
            bb = Gmax - yG[cand]
            j = cand[(-bb**2 / q).argmin()]
            # paso óptimo t a lo largo de α_i += y_i t, α_j -= y_j t (mantiene Σ α y = 0)
            t = (Gmax - yG[j]) / max(K[i, i] + K[j, j] - 2 * K[i, j], 1e-12)
            t = min(t, C - a[i] if y[i] > 0 else a[i], a[j] if y[j] > 0 else C - a[j])
            a[i] += y[i] * t
            a[j] -= y[j] * t
            G += t * y * (K[:, i] - K[:, j])
        self.n_iter_ = it
        # sesgo: promedio sobre los vectores soporte libres (0 < α < C)
        yG = y * G
        free = (a > 1e-12) & (a < C - 1e-12)
        if free.any():
            rho = yG[free].mean()
        else:
            ub = np.min(yG[((a >= C) & (y < 0)) | ((a <= 0) & (y > 0))], initial=np.inf)
            lb = np.max(yG[((a >= C) & (y > 0)) | ((a <= 0) & (y < 0))], initial=-np.inf)
            rho = (ub + lb) / 2
        sv = a > 1e-12
        self.support_ = np.where(sv)[0]
        self.support_vectors_ = X[sv]
        self.dual_coef_ = (a * y)[sv]         # α_i · y_i, como en sklearn
        self.intercept_ = -rho
        return self

    def decision_function(self, X):
        return self.K(X, self.support_vectors_) @ self.dual_coef_ + self.intercept_

    def predict(self, X):
        return np.where(self.decision_function(X) >= 0, 1, -1)

from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import train_test_split, GridSearchCV
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC
from sklearn.linear_model import LogisticRegression

X, y = load_breast_cancer(return_X_y=True)          # 569 casos, 30 variables
Xtr, Xte, ytr, yte = train_test_split(X, y, test_size=0.25, stratify=y, random_state=0)

pipe = make_pipeline(StandardScaler(), SVC(kernel="rbf"))
grid = {"svc__C": [0.1, 1, 10, 100], "svc__gamma": [0.001, 0.01, 0.1, 1]}
gs = GridSearchCV(pipe, grid, cv=5).fit(Xtr, ytr)

print(gs.best_params_)                              # {'svc__C': 100, 'svc__gamma': 0.001}
print("acierto test SVM:", round(gs.score(Xte, yte), 3))         # 0.958
print("vectores soporte:", gs.best_estimator_[-1].n_support_)    # [23 20]
sin_escalar = SVC(kernel="rbf", C=100, gamma=0.001).fit(Xtr, ytr)
print("sin estandarizar:", round(sin_escalar.score(Xte, yte), 3)) # 0.888
log = make_pipeline(StandardScaler(), LogisticRegression(max_iter=5000)).fit(Xtr, ytr)
print("logística:", round(log.score(Xte, yte), 3))               # 0.958

Tres lecturas. El modelo final usa 43 de 426 casos de entrenamiento: eso es lo que se guarda y lo que cuesta cada predicción. Sin escalar, los mismos hiperparámetros pierden 7 puntos, porque unas pocas variables con números grandes dominan las distancias. Y la logística empata: con 30 variables y fronteras casi lineales, la SVM no tiene por qué ganar. Su ventaja aparece con fronteras curvas y pocos datos.

§9 · Checklist

Antes de confiar en tu SVM

  • Escalado dentro del Pipeline, ajustado solo con entrenamiento.
  • Rejilla logarítmica de y ; si el óptimo cae en un borde, amplía la rejilla.
  • Compara con una línea base lineal (logística o LinearSVC).
  • Mira cuántos vectores soporte quedan: si son casi todos, el modelo está memorizando o los datos se solapan mucho.
  • No uses decision_function como probabilidad; calibra si la necesitas.
  • Con más de unos 10⁵ casos, pasa a modelos lineales o aproxima el kernel.

  1. Preparar los datos

    En palabras

    ¿Por qué la velocidad en decenas de km/h?

import numpy as np
from sklearn.svm import SVC

X = np.array([[1, 3], [3, 1], [1, 1], [4, 4], [6, 5], [3, 6]], float)
y = np.array([-1, -1, -1, 1, 1, 1])                  # -1 normal, +1 brusca
svm = SVC(kernel="linear", C=1e6).fit(X, y)         # C enorme = margen duro
print(svm.coef_, svm.intercept_)                    # [[0.5 0.5]] [-3.]
print(svm.support_, svm.dual_coef_)                 # [0 1 3] [[-0.125 -0.125  0.25 ]]
print(svm.decision_function(X))                     # [-1.  -1.  -2.   1.   2.5  1.5]
print(2 / np.linalg.norm(svm.coef_))                # 2.828...
print(svm.decision_function([[5, 2], [2, 2]]))      # [ 0.5 -1. ]

Qué cambiaría en un sistema real

  • Más medidas (duración de la frenada, pendiente, carga, sacudida): la idea es la misma en más dimensiones.
  • Estandarizar en lugar de elegir unidades a ojo, y guardar media y desviación para aplicarlas a las frenadas nuevas.
  • Margen blando: con cientos de frenadas habrá solapes, y se elige por validación cruzada.
  • Kernel RBF si la frontera real es curva (por ejemplo, si a baja velocidad casi ninguna desaceleración es peligrosa).
  • Usar f(x) como nivel de alerta: las frenadas dentro de la calle (|f| < 1) son las dudosas y merecen revisión humana.
