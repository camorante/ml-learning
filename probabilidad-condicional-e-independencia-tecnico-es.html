§2 · Con pandas

De un DataFrame a la tabla y sus condicionales

pd.crosstab cuenta; su argumento normalize elige el denominador: "all" da la conjunta, "index" divide cada fila entre su total (condicional a la variable de las filas) y "columns", cada columna (condicional a la de las columnas). Una condicional binaria también es una media agrupada: df.groupby("lluvia").alerta.mean().

tabla.py

import numpy as np, pandas as pd

# 1 000 viajes: 200 con lluvia (50 con alerta de frenada brusca) y 800 sin lluvia (80 con alerta)
filas = [(True, True)] * 50 + [(True, False)] * 150 + [(False, True)] * 80 + [(False, False)] * 720
df = pd.DataFrame(filas, columns=["lluvia", "alerta"]).sample(frac=1, random_state=0)

print(pd.crosstab(df.lluvia, df.alerta, margins=True, margins_name="total"))
print("-- all"); print(pd.crosstab(df.lluvia, df.alerta, normalize="all"))       # P(lluvia y alerta)
print("-- index"); print(pd.crosstab(df.lluvia, df.alerta, normalize="index"))     # P(alerta | lluvia): cada fila suma 1
print("-- columns"); print(pd.crosstab(df.lluvia, df.alerta, normalize="columns")) # P(lluvia | alerta): cada columna suma 1
print("-- groupby"); print(df.groupby("lluvia").alerta.mean())  # lo mismo que la columna True de 'index'
print(df[df.alerta].lluvia.mean(), df.alerta.mean(), (df.lluvia & df.alerta).mean())

from cond import prob_total, bayes

p_av = 0.02                     # P(avería esta semana)
sens, fa = 0.90, 0.05           # P(alerta | avería), P(alerta | sin avería)
p_alerta = prob_total([p_av, 1 - p_av], [sens, fa])
post = bayes([p_av, 1 - p_av], [sens, fa])[0]
print("P(alerta) =", round(p_alerta, 4), " P(avería | alerta) =", round(post, 4))
# forma de odds: odds a posteriori = odds a priori × razón de verosimilitudes
o0, rv = p_av / (1 - p_av), sens / fa
o1 = o0 * rv; print("odds:", round(o0, 4), "×", rv, "=", round(o1, 4), "->", round(o1 / (1 + o1), 4))
# coste de revisar cada alerta (150 €) por avería encontrada
print("€ por avería encontrada:", round(150 / post, 1))
# segunda señal (vibración), independiente de la primera DADO el estado del camión
s2, f2 = 0.80, 0.10
o2 = o0 * rv * (s2 / f2); print("con dos señales:", round(o2, 4), "->", round(o2 / (1 + o2), 4))
# en 1 000 camiones
print("de 1 000:", 1000 * p_av, 1000 * p_av * sens, 1000 * (1 - p_av) * fa)

§6 · Independencia condicional

Independientes dado C, y Naive Bayes

y son independientes dado () si , o, con , : una vez que sabes , no añade nada sobre . Ninguna de las dos independencias implica la otra:

  • Condicional sin marginal: frenada brusca y exceso de velocidad son independientes dentro de novatos y dentro de veteranos, pero dependientes en la flota, porque el tipo de conductor influye en las dos (causa común).
  • Marginal sin condicional («explaining away», o sesgo de Berkson): una avería de frenos y un sensor defectuoso pueden ser independientes, pero dentro de los camiones que dieron alerta se vuelven dependientes: si el sensor estaba roto, la avería es menos probable. Seleccionar datos por un efecto común crea dependencias.

§7 · Simpson

Cuando el total contradice a cada grupo

Por la probabilidad total, la tasa global de un grupo es la media de sus tasas por estrato ponderada por su mezcla de estratos:

Si dos depósitos tienen pesos distintos, el orden de las medias globales puede invertir el de cada estrato. Con los datos de la versión sencilla:

Depósitociudadautopistatotalmisma mezcla 50/50tarde × 30 €
Norte600/800 = 75 %190/200 = 95 %79 %85 %6 300 €
Sur140/200 = 70 %720/800 = 90 %86 %80 %4 200 €

La columna «misma mezcla» es una estandarización directa: aplicar las tasas de cada depósito a una mezcla de referencia común. ¿Qué cifra es la correcta? Depende de la estructura causal (Pearl, 2014). Aquí el tipo de ruta es una causa común (determina qué depósito la sirve y lo difícil que es llegar a tiempo): hay que estratificar. Si la variable fuera un mediador (algo que el propio depósito causa, como elegir rutas más lentas), estratificar escondería parte del efecto. El caso clásico es el de las admisiones de Berkeley (Bickel, Hammel y O'Connell, 1975): sesgo aparente en el total, ninguno departamento a departamento.

§8 · Desde cero

Tablas, condicionales, Bayes y χ², verificados

El valor p de la χ² necesita la función de supervivencia de la distribución χ², que es la gamma incompleta superior regularizada: . Se calcula con su serie si y con una fracción continua (método de Lentz) en otro caso, como en Numerical Recipes.

cond.py

"""Probabilidad condicional e independencia, desde cero (solo numpy y math)."""
import math
import numpy as np


def tabla(a, b):
    """Tabla de contingencia: filas = valores de a, columnas = valores de b (recuentos)."""
    fa, ia = np.unique(np.asarray(a), return_inverse=True)
    fb, ib = np.unique(np.asarray(b), return_inverse=True)
    T = np.zeros((len(fa), len(fb)), int)
    np.add.at(T, (ia, ib), 1)
    return T, fa, fb


def conjunta(T):
    """P(fila = i y columna = j): cada casilla entre el total."""
    T = np.asarray(T, float); return T / T.sum()


def marginales(T):
    """P(fila = i) y P(columna = j): sumar la conjunta por filas y por columnas."""
    P = conjunta(T); return P.sum(1), P.sum(0)


def condicional(T, dado="filas"):
    """P(columna | fila) si dado='filas' (cada fila suma 1); P(fila | columna) si dado='columnas'."""
    T = np.asarray(T, float)
    return T / T.sum(1, keepdims=True) if dado == "filas" else T / T.sum(0, keepdims=True)


def prob_total(p_b, p_a_dado_b):
    """P(A) = sum_j P(B=j) P(A | B=j)."""
    return float(np.dot(p_b, p_a_dado_b))


def bayes(p_b, p_a_dado_b):
    """P(B=j | A) a partir de P(B=j) y de P(A | B=j): producto y normalizar."""
    num = np.asarray(p_b, float) * np.asarray(p_a_dado_b, float)
    return num / num.sum()


def esperada(T):
    """Recuentos que habría si filas y columnas fueran independientes: n * P(fila) * P(columna)."""
    T = np.asarray(T, float); return np.outer(T.sum(1), T.sum(0)) / T.sum()


def _q_gamma(a, x):
    """Gamma incompleta superior regularizada Q(a, x) (serie o fracción continua de Lentz)."""
    if x <= 0:
        return 1.0
    lg = a * math.log(x) - x - math.lgamma(a)
    if x < a + 1:                                    # serie para P(a, x)
        s = t = 1.0 / a; k = a
        while abs(t) > 1e-17 * abs(s):
            k += 1; t *= x / k; s += t
        return 1.0 - s * math.exp(lg)
    b = x + 1 - a; c = 1e300; d = 1 / b; h = d       # fracción continua para Q(a, x)
    for i in range(1, 10000):
        an = -i * (i - a); b += 2
        d = an * d + b; d = 1e-300 if abs(d) < 1e-300 else d
        c = b + an / c; c = 1e-300 if abs(c) < 1e-300 else c
        d = 1 / d; h *= d * c
        if abs(d * c - 1) < 1e-16:
            break
    return math.exp(lg) * h


def chi2(T, yates=False):
    """Prueba de independencia: estadístico, grados de libertad y valor p."""
    T = np.asarray(T, float); E = esperada(T); d = np.abs(T - E)
    if yates and T.shape == (2, 2):
        d = np.maximum(d - 0.5, 0)
    est = float((d**2 / E).sum()); gl = (T.shape[0] - 1) * (T.shape[1] - 1)
    return est, gl, _q_gamma(gl / 2, est / 2)


def cramer_v(T):
    """Tamaño del efecto entre 0 (independientes) y 1: sqrt(chi2 / (n (min(r, c) - 1)))."""
    T = np.asarray(T, float); est = chi2(T)[0]
    return math.sqrt(est / (T.sum() * (min(T.shape) - 1)))

    err["cols"] = max(err["cols"], np.abs(condicional(T, "columnas") - pd.crosstab(a, b, normalize="columns").values).max())
    pa, pb = marginales(T)
    err["marg"] = max(err["marg"], np.abs(pa - pd.Series(a).value_counts(normalize=True).sort_index().values).max())
    s = stats.chi2_contingency(T, correction=False)
    err["esp"] = max(err["esp"], np.abs(esperada(T) - s.expected_freq).max())
    e, g, p = chi2(T)
    err["chi"] = max(err["chi"], abs(e - s.statistic) / s.statistic); err["p"] = max(err["p"], abs(p - s.pvalue) / max(s.pvalue, 1e-300))
    err["v"] = max(err["v"], abs(cramer_v(T) - association(T, method="cramer")))
    if r == 2 and c == 2:
        s2 = stats.chi2_contingency(T, correction=True)
        err["yates"] = max(err["yates"], abs(chi2(T, yates=True)[0] - s2.statistic))
    # Bayes: P(fila | columna j) a partir de P(fila) y P(columna j | fila)
    j = 0; post = bayes(pa, condicional(T, "filas")[:, j])
    err["bayes"] = max(err["bayes"], np.abs(post - condicional(T, "columnas")[:, j]).max())
    err["bayes"] = max(err["bayes"], abs(prob_total(pa, condicional(T, "filas")[:, j]) - pb[j]))
for k, v in err.items():
    print(f"{k:6s} {v:.1e}")

§9 · En la flota

200 000 viajes simulados

Lluvia en el 20 % de los viajes, conductores novatos en el 30 % (independiente de la lluvia), alerta de frenada según lluvia y conductor (7, 17, 19 y 39 %, elegidos para que salgan el 10 % y el 25 % de la versión sencilla) y exceso de velocidad que depende solo del conductor (30 % novatos, 10 % veteranos).

sim.py

import numpy as np, pandas as pd
from cond import chi2


def viajes(n=200_000, seed=9):
    """Viajes simulados: lluvia (20 %), conductor novato (30 %, independiente de la lluvia),
    alerta de frenada brusca según lluvia y conductor, y exceso de velocidad según el conductor."""
    r = np.random.default_rng(seed)
    lluvia = r.random(n) < 0.20
    novato = r.random(n) < 0.30
    p_alerta = np.select([~lluvia & ~novato, ~lluvia & novato, lluvia & ~novato], [0.07, 0.17, 0.19], 0.39)
    alerta = r.random(n) < p_alerta
    exceso = r.random(n) < np.where(novato, 0.30, 0.10)
    return pd.DataFrame(dict(lluvia=lluvia, novato=novato, alerta=alerta, exceso=exceso))

r = np.random.default_rng(1); est, nB = [], []
for _ in range(1000):

    est.append(b.alerta.mean()); nB.append(len(b))

      " casos de media", np.mean(nB), " teórica", round(np.sqrt(0.39 * 0.61 / 30), 3))

Tres lecturas. Las condicionales simuladas recuperan las del modelo (0,100 y 0,250; ). Alerta y exceso son claramente dependientes en la flota () e independientes dentro de cada tipo de conductor ( y ): independencia condicional por causa común. Y una condicional sobre un grupo pequeño es ruidosa: con 500 viajes solo hay unos 30 de lluvia con novato, y tiene desviación típica 0,09, la binomial . Cada condición añadida divide los datos: las tablas de varias entradas se quedan vacías enseguida, y por eso los modelos (regresión logística, Naive Bayes) imponen estructura en vez de contar casilla a casilla.

§10 · Checklist

Antes de fiarte de una probabilidad condicional

  • Está claro qué es el denominador: divide entre los casos con (y en crosstab, el eje de normalize es el correcto).
  • No se ha transpuesto la condicional: para pasar de a se usan las tasas base (Bayes).
  • El grupo condicionante tiene casos suficientes; se da el intervalo o al menos .
  • Si se compara una condicional con la general, se mira el tamaño (diferencia, cociente, V de Cramér) y no solo el valor p.
  • Recuentos esperados ≥ 5 para la χ²; si no, Fisher.
  • Se han buscado variables que expliquen a la vez las dos (tipo de conductor, tipo de ruta) y se ha comparado dentro de sus grupos.
  • Antes de comparar totales entre grupos, se ha comprobado que la mezcla es parecida o se ha estandarizado.
  • Si un modelo supone independencia (Naive Bayes, binomial, Poisson), se ha comprobado al menos con una tabla.

§11 · Ejemplo resuelto

Lluvia y alertas de frenada, a mano

La tabla de 1 000 viajes de la versión sencilla, de principio a fin: marginales, las tres divisiones de una casilla, la regla del producto, la probabilidad total en un mes de invierno, darle la vuelta con Bayes y la prueba de independencia.

La situación. La jefa de tráfico ve que en los viajes con alerta de frenada brusca llovió en el 38,5 % de los casos y quiere saber tres cosas: cuánto sube el riesgo de alerta cuando llueve, cuántas alertas esperar en invierno y si la relación es real o puede ser casualidad.

Mapa del ejemplo

1 000 viajes de la flota: en 200 llovió, en 130 hubo alerta de frenada brusca y en 50 pasaron las dos cosas. Con solo esos tres números se calcula todo lo del tema: marginales, conjunta y las dos condicionales, la regla del producto, la probabilidad total en un mes más lluvioso, Bayes y la prueba de independencia.

  1. Completar la tabla y sacar las marginales.
  2. La misma casilla, tres divisiones.
  3. La regla del producto, por los dos lados.
  4. Probabilidad total: un mes de invierno.
  5. Darle la vuelta: Bayes.
  6. ¿Independientes? La prueba χ².

  1. Completar la tabla y sacar las marginales

    En palabras

    Con el total de cada fila y columna y una casilla, el resto de la tabla sale restando. Después, cada total entre 1 000 es una probabilidad «marginal» (se llama así porque se escribe en el margen de la tabla).

    Los datos

    alertasin alertatotal
    lluvia50150200
    sin lluvia80720800
    total1308701 000

    ¿De dónde salen los números?

    Son los viajes del juguete de la versión sencilla: la telemetría marca la alerta cuando la deceleración pasa de un umbral, y la lluvia sale del parte meteorológico de la zona por la que pasaba el camión. Las casillas que faltan salen restando: 150 = 200 − 50, 80 = 130 − 50 y 720 = 800 − 80; los totales, 800 = 1 000 − 200 viajes sin lluvia y 870 = 1 000 − 130 sin alerta.

  2. La misma casilla, tres divisiones

    En palabras

    Los 50 viajes con lluvia y alerta se pueden dividir entre todos los viajes, entre los de lluvia o entre los de alerta. Cada división responde a una pregunta distinta.

    La cuenta

    ¿Qué significa cada símbolo?

    se lee «y» (los dos sucesos a la vez). La barra se lee «sabiendo que» o «si»: lo que va detrás es lo que ya se sabe, y por eso es lo que va en el denominador. Sin lluvia, la alerta sale en .

    Qué significa: si llueve, la alerta pasa del 10 % al 25 %: 2,5 veces más probable. Y entre los viajes con alerta, el 38,5 % fue con lluvia, casi el doble del 20 % general. Son dos números distintos para dos preguntas distintas.

  3. La regla del producto, por los dos lados

    En palabras

    La probabilidad de «lluvia y alerta» se puede construir de dos maneras: primero la lluvia y luego la alerta sabiendo que llovió, o primero la alerta y luego la lluvia sabiendo que hubo alerta. Las dos tienen que dar lo mismo.

    La cuenta

    ¿Por qué funciona?

    Es la definición de condicional despejada: si , multiplicando por sale . En recuentos: , el 200 se cancela.

  4. Probabilidad total: un mes de invierno

    En palabras

    En enero llueve en el 40 % de los viajes, no en el 20 %. Si los conductores conducen igual (las condicionales 25 % y 10 % no cambian), ¿cuántas alertas habrá? Se suman los dos caminos del árbol que acaban en alerta.

    La cuenta

    ¿De dónde sale cada número?

    0,60 es , los viajes sin lluvia. Los 6 € son el coste supuesto de revisar cada alerta: un supervisor mira el vídeo de la cámara unos 10 minutos, a unos 36 € la hora. Con el 20 % de lluvia eran 130 alertas,  €.

    Qué significa: en invierno habrá un 23 % más de alertas (160 frente a 130) y 180 € más de revisiones por cada 1 000 viajes, sin que nadie conduzca peor. Antes de comparar las alertas de enero con las de julio, hay que tener en cuenta la mezcla.

  5. Darle la vuelta: Bayes

    En palabras

    Supón que solo conoces lo de antes: lluvia en el 20 % de los viajes, alerta en el 25 % si llueve y en el 13 % en general. ¿Qué parte de las alertas son de viajes con lluvia? Es pasar de P(alerta | lluvia) a P(lluvia | alerta). Para abreviar, = lluvia y = alerta.

    La cuenta

    ¿Qué son las odds?

    Las odds (o «apuestas») son la probabilidad de que pase entre la de que no pase: es «1 viaje con lluvia por cada 4 sin lluvia». El 2,5 es la razón de verosimilitudes: cuántas veces más frecuente es la alerta con lluvia que sin ella (). Saber que hubo alerta multiplica las odds de lluvia por 2,5. Para volver a probabilidad: odds / (1 + odds).

    Qué significa: el mismo 38,5 % del paso 2, ahora sin mirar la casilla: a partir de cuánto llueve y de cuánto sube la alerta con lluvia. Eso es todo el teorema de Bayes: la regla del producto leída al revés.

  6. ¿Independientes? La prueba χ²

    En palabras

    Si la lluvia no influyera en las alertas, cada casilla tendría «total de su fila × total de su columna / 1 000» viajes. Se compara lo que hay con eso, casilla a casilla, y se suma.

    La cuenta

    ¿De dónde salen el 3,84 y la V?

    Si fueran independientes, el estadístico χ² de una tabla 2×2 seguiría una distribución χ² con 1 grado de libertad (una tabla 2×2 con los totales fijos solo tiene una casilla libre: las otras tres salen restando). Esa distribución supera 3,84 solo el 5 % de las veces; 3,84 es , el cuadrado del 1,96 de la normal (tema 8). 31,83 está muy lejos: la probabilidad de algo así por azar es . La V de Cramér divide entre para medir la fuerza de la relación sin que influya el tamaño: 0 es independencia y 1, relación total.

    Qué significa: la relación entre lluvia y alertas no es casualidad, pero es moderada (V = 0,18): la lluvia sube la alerta del 10 % al 25 %, no la decide. Con solo 100 viajes y las mismas proporciones, χ² saldría 3,18 y no se podría descartar el azar.

ejemplo.py · reproduce los números de arriba

import numpy as np
from scipy import stats

T = np.array([[50, 150], [80, 720]])           # filas: lluvia sí / no; columnas: alerta sí / no
n = T.sum(); fil, col = T.sum(1), T.sum(0)
print("1. totales", fil, col, n, " P(lluvia) =", fil[0] / n, " P(alerta) =", col[0] / n)
print("2. 50 entre:", 50 / n, 50 / fil[0], round(50 / col[0], 4))
print("3. producto:", 0.20 * 0.25, round(0.13 * (50 / 130), 4))
print("4. invierno:", round(0.40 * 0.25 + 0.60 * 0.10, 4), " alertas de 1 000:", round(1000 * (0.40 * 0.25 + 0.60 * 0.10)),
      " × 6 € =", round(1000 * (0.40 * 0.25 + 0.60 * 0.10)) * 6, "frente a", 130 * 6)
print("5. Bayes:", round(0.20 * 0.25 / 0.13, 4), " odds", 0.2 / 0.8, "×", 0.25 / 0.10, "=", 0.25 * 2.5, "->", round(0.625 / 1.625, 4))
E = np.outer(fil, col) / n
c = (T - E) ** 2 / E
print("6. esperada", E.tolist(), " sumandos", c.round(2).tolist(), " chi2 =", round(c.sum(), 2),
      " crítico", round(stats.chi2.ppf(0.95, 1), 2), " p =", f"{stats.chi2.sf(c.sum(), 1):.1e}", " V =", round(np.sqrt(c.sum() / n), 3))

Qué cambiaría en un sistema real

  • Más variables a la vez: noche, tipo de conductor, tipo de vía. Antes de atribuir las alertas a la lluvia, comparar dentro de cada grupo (§6, §7).
  • Unidad de análisis: viajes de un mismo camión o conductor no son independientes entre sí; la χ² supone que cada fila es un caso independiente.
  • Exposición: un viaje con lluvia puede ser más largo; mejor alertas por cada 100 km que «viaje con alerta sí o no».
  • Intervalos: dar con su intervalo (con 200 viajes, intervalo de Wilson del 95 % de 0,20 a 0,31).
