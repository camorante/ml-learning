Random Forest y Boosting para programadores

Dos maneras opuestas de combinar árboles: promediar muchos árboles independientes para quitarles varianza, o sumar árboles pequeños en serie, cada uno bajando por el gradiente de la pérdida, para quitarles sesgo. Con un Random Forest y un Gradient Boosting desde cero verificados contra scikit-learn y un ejemplo resuelto a mano.

Resumen

  • Promediar modelos con varianza y correlación deja una varianza : el término que no baja con es la correlación.
  • Bagging entrena cada árbol con una muestra bootstrap; cada fila queda fuera del ≈ 36.8 % de los árboles, lo que da una validación gratis (OOB).
  • Random Forest añade max_features: cada corte solo considera un subconjunto aleatorio de variables, lo que baja .
  • Gradient boosting es descenso de gradiente en el espacio de funciones: cada árbol ajusta los pseudo-residuos y se suma con un paso .
  • XGBoost, LightGBM y HistGradientBoosting usan además un paso de Newton por hoja, regularización y cortes sobre histogramas. Hay que parar a tiempo.

Bagging solo ayuda a modelos inestables (árboles profundos, redes): a una regresión lineal apenas la cambia. Y no reduce el sesgo: un bosque de árboles de profundidad 1 sigue siendo un modelo aditivo de escalones.

§3 · Random Forest

Decorrelar con variables al azar

Si una variable es muy predictiva, casi todos los árboles con bagging la usan en la raíz y se parecen: alto. Random Forest (Breiman 2001) añade un segundo azar: en cada nodo, el mejor corte se busca solo entre variables elegidas al azar de las .

Importancia de variables. La importancia por impureza (MDI, feature_importances_) suma la caída de Gini de cada variable en todos los árboles: es gratis pero está sesgada hacia variables continuas o con muchas categorías, y se mide en entrenamiento. La importancia por permutación baraja una columna en datos de validación y mide cuánto empeora la métrica: más lenta pero honesta. Con variables correlacionadas, ambas reparten (o esconden) la importancia entre ellas.

Lo que un bosque no hace: extrapolar. Cada árbol predice medias de hojas, así que la predicción está siempre dentro del rango de en entrenamiento; fuera del rango de , se queda plana.

§7 · Regularización

Tasa de aprendizaje, submuestreo y parada temprana

Al contrario que un bosque, boosting sí sobreajusta con demasiados árboles: el error de entrenamiento tiende a 0 y el de validación tiene forma de U. Las perillas, por orden de importancia:

  • y van juntos: con menor hacen falta más árboles, pero el mínimo de validación suele ser más bajo y más plano. Regla práctica: fija y elige con parada temprana.
  • Tamaño de cada árbol (max_depth 3–8 o max_leaf_nodes 15–63): controla el orden de las interacciones que puede capturar cada paso.
  • Submuestreo (subsample 0.5–0.8, stochastic gradient boosting): cada árbol ve una fracción de filas; regulariza y acelera. También colsample por variables, como en un bosque.

import numpy as np
from sklearn.tree import DecisionTreeClassifier

class RandomForest:
    """Bagging de árboles + variables al azar en cada corte (max_features)."""
    def __init__(self, n_estimators=100, max_features="sqrt", random_state=0):
        self.B, self.mf, self.rs = n_estimators, max_features, random_state

    def fit(self, X, y):
        n = len(y)
        seeds = np.random.RandomState(self.rs).randint(np.iinfo(np.int32).max, size=self.B)
        self.trees, votes, seen = [], np.zeros((n, 2)), np.zeros(n)
        for s in seeds:
            idx = np.random.RandomState(s).randint(0, n, n)      # bootstrap: n extracciones con reemplazo
            w = np.bincount(idx, minlength=n)                    # repetir una fila = darle más peso
            t = DecisionTreeClassifier(max_features=self.mf, random_state=s).fit(X, y, sample_weight=w)
            self.trees.append(t)
            oob = w == 0                                         # ≈ 36.8 % de las filas
            votes[oob] += t.predict_proba(X[oob]); seen[oob] += 1
        ok = seen > 0
        self.oob_score_ = np.mean(votes[ok].argmax(1) == y[ok])  # exactitud fuera de la bolsa
        return self

    def predict_proba(self, X):
        return np.mean([t.predict_proba(X) for t in self.trees], axis=0)   # promedio de probabilidades

import numpy as np
from scipy.special import expit, logit
from sklearn.tree import DecisionTreeRegressor

class GBRegressor:
    """Gradient boosting con pérdida cuadrática: cada árbol ajusta los residuos."""
    def __init__(self, n_estimators=100, learning_rate=0.1, max_depth=3, random_state=0):
        self.M, self.nu, self.depth, self.rs = n_estimators, learning_rate, max_depth, random_state

    def fit(self, X, y):
        self.f0 = y.mean()                                   # F_0: la constante que minimiza la pérdida
        F = np.full(len(y), self.f0)
        self.trees = []
        rng = np.random.RandomState(self.rs)                 # un solo generador, como sklearn (desempates)
        for m in range(self.M):
            r = y - F                                        # -gradiente de ½(y-F)² = residuo
            t = DecisionTreeRegressor(max_depth=self.depth, random_state=rng).fit(X, r)
            F += self.nu * t.predict(X)                      # paso encogido (shrinkage)
            self.trees.append(t)
        return self

    def predict(self, X):
        return self.f0 + self.nu * sum(t.predict(X) for t in self.trees)

class GBClassifier:
    """Gradient boosting binario con log-loss y valores de hoja de Newton."""
    def __init__(self, n_estimators=100, learning_rate=0.1, max_depth=3, random_state=0):
        self.M, self.nu, self.depth, self.rs = n_estimators, learning_rate, max_depth, random_state

    def fit(self, X, y):
        self.f0 = logit(y.mean())                            # log-odds inicial: log(p/(1-p))
        F = np.full(len(y), self.f0)
        self.trees = []
        rng = np.random.RandomState(self.rs)
        for m in range(self.M):
            g = y - expit(F)                                 # -gradiente de la log-loss: y - p
            p = y - g                                        # = expit(F), redondeado igual que sklearn
            h = p * (1 - p)                                  # hessiano
            t = DecisionTreeRegressor(max_depth=self.depth, random_state=rng).fit(X, g)
            leaf = t.apply(X)
            vals = {}
            for l in np.unique(leaf):                        # paso de Newton en cada hoja: Σg / Σh
                i = leaf == l
                vals[l] = g[i].mean() / h[i].mean()
            F += self.nu * np.array([vals[l] for l in leaf])
            self.trees.append((t, vals))
        return self

    def decision_function(self, X):
        F = np.full(len(X), self.f0)
        for t, vals in self.trees:
            F += self.nu * np.array([vals[l] for l in t.apply(X)])
        return F

    def predict_proba(self, X):
        return expit(self.decision_function(X))

§10 · Checklist

Antes de confiar en tu ensamble

  • Boosting: usa siempre parada temprana con un conjunto de validación que no sea el de prueba final.
  • Si los datos tienen tiempo (viajes, telemetría), valida con cortes temporales; el OOB de un bosque asume filas independientes y será optimista.
  • Busca fugas de información: los ensambles encuentran enseguida un identificador o una variable posterior al evento.
  • Importancia por permutación en validación, no MDI; con variables correlacionadas, permuta grupos.
  • Probabilidades: los bosques tienden a ser poco extremos y el boosting sobreconfiado; revisa la curva de calibración.
  • No esperes extrapolación: si en producción aparecen valores fuera del rango de entrenamiento, el modelo devolverá el borde.
  • Compara con una línea base simple (regresión logística, un árbol podado): si gana por poco, quizá no compense la complejidad.

import numpy as np
from sklearn.ensemble import GradientBoostingRegressor
from sklearn.tree import DecisionTreeRegressor

km = np.array([[5], [10], [15], [20], [25], [30]])
minutos = np.array([2, 4, 3, 12, 14, 19])

gb = GradientBoostingRegressor(n_estimators=3, learning_rate=0.5, max_depth=1).fit(km, minutos)
print([round(((minutos - p) ** 2).sum(), 2) for p in gb.staged_predict(km)])   # [82.0, 36.44, 16.13]
print(gb.predict([[17]]))                                                      # [4.4]

muestras = [[0, 1, 1, 3, 4, 5], [0, 2, 2, 3, 3, 5], [1, 2, 3, 4, 4, 5]]       # las 3 del paso 2
arboles = [DecisionTreeRegressor(max_depth=1).fit(km, minutos, sample_weight=np.bincount(m, minlength=6))
           for m in muestras]
print([round(a.predict([[17]])[0], 2) for a in arboles])                       # [15.0, 2.67, 3.5]

Qué cambiaría en un sistema real

  • Miles de entregas y decenas de variables (hora, día, zona, tráfico, conductor, clima): con una sola variable un ensamble apenas tiene dónde lucirse.
  • Cientos de árboles más profundos, entre 0.03 y 0.1 y parada temprana con datos de validación.
  • Validación temporal: entrenar con semanas anteriores y medir en la siguiente.
  • Predecir un intervalo, no solo un número: con pérdida cuantil (loss="quantile") se puede estimar, por ejemplo, el retraso que solo se supera el 10 % de las veces.
