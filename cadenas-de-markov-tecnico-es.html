§6 · Más allá

Variantes y límites

  • Duraciones geométricas. El tiempo en un estado sigue una geométrica de media , siempre con moda en 1 paso. Para duraciones realistas: dividir el estado en etapas (distribuciones tipo fase), modelos semi-Markov o HSMM.
  • Orden superior. Si importan los dos últimos estados, se usa como estado el par . Los parámetros crecen como .
  • Tiempo continuo. Con eventos a tiempos irregulares, una cadena en tiempo continuo con generador (filas que suman 0) da para cualquier intervalo.
  • No homogénea. Probabilidades que dependen de covariables (hora, clima) se modelan con una regresión logística multinomial por fila.
  • Estado continuo. Si el estado oculto es una posición y las emisiones son gaussianas lineales, el HMM se convierte en el filtro de Kalman (el siguiente tema): forward pasa a ser predecir y corregir con medias y covarianzas.
  • Otros usos: PageRank es la de un paseo aleatorio por la web, y MCMC construye una cadena cuya es la distribución de la que se quiere muestrear.

markov.py · verificado: π igual a p₀Pⁿ con n = 200; tiempos de llegada iguales a una simulación de 20 000 trayectorias (8.07 frente a 8); con 200 000 pasos simulados, fit_transitions recupera P a ±0.002; forward igual a la suma por fuerza bruta de las 3⁹ trayectorias (diferencia 6·10⁻¹⁴) y a hmmlearn en 500 pasos (2·10⁻¹²); viterbi igual a la fuerza bruta y con la misma log-probabilidad que hmmlearn (solo difiere en empates exactos)

import numpy as np

# ---------- Cadena de Markov ----------
def fit_transitions(seq, k, alpha=0.0):
    """Estima P contando transiciones i→j (alpha > 0: suavizado de Laplace)."""
    C = np.full((k, k), alpha, float)
    np.add.at(C, (seq[:-1], seq[1:]), 1)
    return C / C.sum(1, keepdims=True)

def n_step(p0, P, n):
    """Distribución tras n pasos: p0 · Pⁿ."""
    return p0 @ np.linalg.matrix_power(P, n)

def stationary(P):
    """π con π P = π: autovector por la izquierda de autovalor 1."""
    w, V = np.linalg.eig(P.T)
    v = np.real(V[:, np.argmin(np.abs(w - 1))])
    return v / v.sum()

def hitting_times(P, target):
    """Pasos esperados hasta llegar a 'target' desde cada estado: h = 1 + Q h."""
    others = [i for i in range(len(P)) if i != target]
    Q = P[np.ix_(others, others)]
    h = np.linalg.solve(np.eye(len(others)) - Q, np.ones(len(others)))
    out = np.zeros(len(P)); out[others] = h
    return out

# ---------- Modelo oculto de Markov (observaciones discretas) ----------
def forward(obs, pi0, A, B):
    """log P(observaciones) con forward escalado; devuelve también P(estado_t | obs_1..t)."""
    alpha = pi0 * B[:, obs[0]]
    c = [alpha.sum()]; alpha /= c[0]; filt = [alpha]
    for o in obs[1:]:
        alpha = (alpha @ A) * B[:, o]
        c.append(alpha.sum()); alpha /= c[-1]; filt.append(alpha)
    return np.log(c).sum(), np.array(filt)

def viterbi(obs, pi0, A, B):
    """Secuencia de estados más probable (en logaritmos para no desbordar)."""
    lA, lB = np.log(A), np.log(B)
    d = np.log(pi0) + lB[:, obs[0]]
    back = []
    for o in obs[1:]:
        s = d[:, None] + lA                   # s[i, j]: venir de i y pasar a j
        back.append(s.argmax(0))
        d = s.max(0) + lB[:, o]
    path = [int(d.argmax())]
    for b in reversed(back):
        path.append(int(b[path[-1]]))
    return path[::-1], d.max()

§8 · En producción

Con bibliotecas: aprender un HMM sin etiquetas

hmm_flota.py · salida real en los comentarios (hmmlearn 0.3.3)

import numpy as np
from itertools import permutations
from hmmlearn.hmm import CategoricalHMM

# "Verdad" que queremos recuperar: ruta / parado / cargando, y lo que ve el GPS
A = np.array([[.9, .07, .03], [.15, .75, .1], [.05, .05, .9]])  # transiciones cada 15 min
B = np.array([[.1, .25, .65], [.3, .6, .1], [.75, .25, .0]])   # GPS: detenido, lento, rápido
real = CategoricalHMM(n_components=3); real.startprob_ = [.5, .25, .25]; real.transmat_ = A; real.emissionprob_ = B
dias = [real.sample(96, random_state=d) for d in range(60)]   # 60 secuencias de 96 pasos
X = np.concatenate([x for x, z in dias]); Z = np.concatenate([z for x, z in dias]); lens = [96] * 60

# Baum-Welch (EM) sin conocer los estados: varios arranques, nos quedamos con el mejor
mejor = max((CategoricalHMM(n_components=3, n_iter=500, tol=1e-6, random_state=s).fit(X, lens) for s in range(10)),
            key=lambda m: m.score(X, lens))
# los estados aprendidos salen en cualquier orden: buscamos la permutación que mejor encaja
perm = max(permutations(range(3)), key=lambda p: np.mean(np.array(p)[mejor.predict(X, lens)] == Z))
inv = np.argsort(perm)
print(mejor.transmat_[np.ix_(inv, inv)].round(2))
# [[0.89 0.09 0.02]
#  [0.14 0.76 0.1 ]
#  [0.04 0.06 0.9 ]]
print(mejor.emissionprob_[inv].round(2))
# [[0.09 0.24 0.68]
#  [0.28 0.58 0.14]
#  [0.77 0.23 0.  ]]
print("acierto de Viterbi con el modelo aprendido: ", round(np.mean(np.array(perm)[mejor.predict(X, lens)] == Z), 3))  # 0.817
print("acierto de Viterbi con el modelo real:      ", round(np.mean(real.predict(X, lens) == Z), 3))                  # 0.827
ingenua = np.array([2, 1, 0])[X.ravel()]                       # rápido→ruta, lento→parado, detenido→cargando
print("regla ingenua, símbolo a símbolo:           ", round(np.mean(ingenua == Z), 3))                               # 0.678

Eso son 14 puntos más que la regla que mira cada lectura por separado. Los estados aprendidos no tienen nombre: hay que ponérselo mirando las emisiones (aquí, con la permutación que mejor encaja con la verdad, que en producción no se tiene).

§9 · Checklist

Antes de confiar en tu cadena

  • El paso de tiempo es fijo y los datos están remuestreados a ese paso (sin huecos tratados como transiciones).
  • Cada fila tiene suficientes transiciones; si no, suaviza o agrupa estados.
  • Comprueba la homogeneidad: estima por franjas horarias y compara.
  • Compara las duraciones simuladas con las reales; si no encajan, divide estados en etapas.
  • Valida con datos de otros días: verosimilitud por paso o acierto al predecir el siguiente estado.
  • En un HMM, varios arranques de EM, revisa que las emisiones tengan sentido y ponles nombre a mano.

N = np.array([[140, 40, 20], [32, 32, 16], [16, 16, 48]])   # conteos de la semana
P = N / N.sum(1, keepdims=True)                           # [[.7 .2 .1] [.4 .4 .2] [.2 .2 .6]]

Qué cambiaría en un sistema real

  • Una tabla por franja horaria: de noche casi nadie carga, y una única promedia cosas distintas.
  • Más estados: taller, ralentí o espera en cliente, siempre que cada fila tenga transiciones suficientes.
  • Estados con etapas para que la duración de las cargas se parezca a la real (§6).
  • Estados ocultos: si los estados salen de reglas sobre el GPS, mejor un HMM que los infiera con su incertidumbre.
