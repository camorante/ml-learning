Cancelación catastrófica, dos pasadas y Welford

Con , la identidad de §1 da la fórmula «de una pasada» de los libros:

Matemáticamente correcta, numéricamente peligrosa: resta dos números enormes y casi iguales. Si (lecturas de odómetro, marcas de tiempo en milisegundos, coordenadas proyectadas), los dos términos coinciden en casi todas sus cifras y la diferencia es ruido de redondeo, o incluso negativa. El número de condición del problema (Chan, Golub y LeVeque) es ; la fórmula de una pasada amplifica los errores de redondeo en un factor del orden de y la de dos pasadas (primero , luego ) no. Desplazar los datos por cualquier valor cercano (el primero, por ejemplo) antes de usar la de una pasada también reduce .

El incremento , así que nunca se vuelve negativa por cancelación. Y dos resúmenes , se fusionan exactamente (Chan et al.): es la identidad de §1 aplicada a cada trozo con = la media conjunta.

Esto es lo que hace práctico el streaming: un listener de telemetría guarda tres números por camión y variable; cada partición (un día, un servidor, un worker de Spark o de BigQuery) calcula su resumen y se fusionan en árbol (que además acumula menos error que fusionar en cadena). Es la misma «ley de la varianza total»: dentro de los grupos más entre las medias de los grupos.

§6 · Desde cero

Un módulo de resúmenes, verificado

resumen.py

"""Media, mediana, varianza y compañía, desde cero (solo NumPy para los arrays)."""
import math
import numpy as np


def media(x):
    x = np.asarray(x, float)
    m = x.sum() / len(x)
    return m + (x - m).sum() / len(x)          # segunda pasada: corrige el redondeo de la primera


def mediana(x):
    s = np.sort(np.asarray(x, float)); n = len(s); k = n // 2
    return s[k] if n % 2 else (s[k - 1] + s[k]) / 2


def varianza(x, ddof=1):
    """Dos pasadas corregida (Björck): suma de cuadrados respecto a la media, menos el error de redondeo de la media."""
    x = np.asarray(x, float); n = len(x)
    if n - ddof <= 0:
        return math.nan
    d = x - media(x)
    return (np.dot(d, d) - d.sum() ** 2 / n) / (n - ddof)


def desviacion(x, ddof=1):
    return math.sqrt(varianza(x, ddof))


def varianza_ingenua(x, ddof=1):
    """La fórmula de una pasada de los libros: (Σx² − (Σx)²/n) / (n − ddof). NO usar: cancelación catastrófica."""
    x = np.asarray(x); n = len(x)
    return (np.sum(x * x) - np.sum(x) ** 2 / n) / (n - ddof)


def cv(x, ddof=1):
    """Coeficiente de variación: desviación típica / media (solo con datos positivos en una escala con cero real)."""
    return desviacion(x, ddof) / media(x)


def zscore(x, ddof=0):
    """Estandarizar: (x − media) / desviación. ddof=0 como StandardScaler y scipy.stats.zscore."""
    x = np.asarray(x, float)
    return (x - media(x)) / desviacion(x, ddof)


def mad(x, escala=1.0):
    """Mediana de las distancias a la mediana. Con escala=1.4826 estima σ si los datos fueran normales (tema 8)."""
    x = np.asarray(x, float)
    return escala * mediana(np.abs(x - mediana(x)))


def media_recortada(x, prop=0.1):
    """Quita el prop de valores más bajos y el prop de los más altos (redondeando hacia abajo) y promedia el resto."""
    s = np.sort(np.asarray(x, float)); k = int(prop * len(s))
    return media(s[k:len(s) - k])


def media_ponderada(x, w):
    x = np.asarray(x, float); w = np.asarray(w, float)
    return np.dot(w, x) / w.sum()


class Welford:
    """Media y varianza en streaming: una pasada, memoria O(1), estable. fusionar() une dos resúmenes (Chan et al.)."""

    def __init__(self):
        self.n, self.m, self.M2 = 0, 0.0, 0.0

    def add(self, x):
        self.n += 1
        d = x - self.m
        self.m += d / self.n
        self.M2 += d * (x - self.m)              # d · (x − media nueva): siempre ≥ 0
        return self

    def fusionar(self, o):
        n = self.n + o.n
        if n == 0:
            return self
        d = o.m - self.m
        self.m += d * o.n / n
        self.M2 += o.M2 + d * d * self.n * o.n / n
        self.n = n
        return self

    def varianza(self, ddof=1):
        return self.M2 / (self.n - ddof) if self.n > ddof else math.nan

    def desviacion(self, ddof=1):
        return math.sqrt(self.varianza(ddof))

"""Flota simulada: 300 camiones × 80 viajes, consumo (L/100 km) y ralentí (min), con registros erróneos."""
import numpy as np, pandas as pd


def viajes(seed=1, camiones=300, n=80, p_error=0.004):
    rng = np.random.default_rng(seed)
    base = rng.normal(32, 2.0, camiones)                          # consumo propio de cada camión
    cam = np.repeat(np.arange(camiones), n)
    dia = np.tile(np.arange(n) // 4, camiones)                    # 4 viajes por día, 20 días
    consumo = base[cam] + rng.normal(0, 1.8, len(cam))
    ralenti = rng.gamma(2.0, 9.0, len(cam))                       # minutos de motor al ralentí por viaje
    malo = rng.random(len(cam)) < p_error                         # coma perdida: 33.4 se guarda como 334
    consumo[malo] *= 10
    return pd.DataFrame(dict(camion=cam, dia=dia, consumo=consumo.round(1), ralenti=ralenti.round(0), error=malo)), base

La media por camión marca 75 camiones como gastones y 61 son falsas alarmas: basta un registro de 330 entre 80 para subir la media más de 3 L/100 km. Mediana y media recortada aciertan los 14 sin falsas alarmas. Con 80 viajes por camión, la clásica encuentra los 106 errores (la cota de Shiffler es 8,8). Con solo 8 viajes, no encuentra ninguno (la cota es 2,47); mediana y MAD los encuentran todos, a cambio de 59 falsas alarmas: con 8 datos, la MAD es una escala muy ruidosa. Lo razonable en producción es filtrar primero por rango físico (nadie gasta 300 L/100 km) y después aplicar reglas estadísticas.

§8 · Checklist

Antes de publicar una media y una desviación típica

  • Media y mediana calculadas juntas; si difieren más de una fracción de , mirar los datos antes de seguir.
  • Valores imposibles filtrados por rango físico (consumo, velocidad, coordenadas) antes de cualquier regla basada en .
  • Divisor explícito (ddof) y documentado; el mismo en todos los sistemas que comparan resultados.
  • Cocientes agregados como total / total (o media ponderada), no como media de cocientes.
  • Varianza calculada en dos pasadas o con Welford; nunca , y menos en float32.
  • Datos dependientes (muestras GPS de un mismo viaje) agregados a la unidad independiente antes de hablar de incertidumbre.
  • Parámetros de estandarizado ajustados solo con entrenamiento y guardados con el modelo.
  • La forma de los datos dibujada al menos una vez: dos grupos o una cola larga no se ven en dos números.

§9 · Ejemplo resuelto

Ocho viajes, a mano

Media, desviaciones, varianza con y con , la identidad de la suma de cuadrados, el registro erróneo, coeficiente de variación, y Welford paso a paso, con los números del juguete de la versión sencilla.

La situación. El responsable de flota quiere un informe semanal de consumo por camión: «cuánto gasta y cuánto varía». Antes de automatizarlo, lo hace a mano con un camión y 8 viajes, y se encuentra con que uno de los registros llegó como 370.

Mapa del ejemplo

Un camión, 8 viajes y su consumo en L/100 km: 32, 35, 30, 33, 37, 31, 34 y 32 (los del juguete de la versión sencilla). Calculamos a mano el centro y la dispersión, comprobamos por qué la media es el mejor número «al cuadrado», vemos qué hace un registro guardado como 370, comparamos con los minutos de ralentí y repetimos la cuenta como lo haría un programa que recibe los viajes de uno en uno.

  1. La media.
  2. Las desviaciones, y por qué suman 0.
  3. Varianza y desviación típica: entre 8 y entre 7.
  4. La media es el número que menos se equivoca.
  5. La mediana y el registro de 370.
  6. Otra columna: coeficiente de variación y z.
  7. Lo mismo, dato a dato (Welford).

  1. La media

    En palabras

    Sumamos los 8 consumos y dividimos entre cuántos hay. El símbolo («x barra») es la media; es el número de datos.

    La cuenta

    Qué significa: si el camión gastara siempre lo mismo, gastaría 33 L/100 km y habría consumido el mismo combustible en los 8 viajes (si los viajes fueran igual de largos; si no, ver la media ponderada de §4).

  2. Las desviaciones, y por qué suman 0

    En palabras

    A cada viaje le restamos la media: . Positivo si gastó más que la media, negativo si gastó menos.

    La cuenta

    viaje12345678
    x3235303337313432
    d = x − 33−1+2−30+4−2+1−1
    d²149016411

    ¿Por qué siempre 0?

    : la media se define justo para que sea así. Es el «punto de equilibrio» del juguete. Por eso la media de las desviaciones no sirve como medida de dispersión y hay que quitarles el signo.

  3. Varianza y desviación típica: entre 8 y entre 7

    La cuenta (suma de cuadrados de la tabla: 1 + 4 + 9 + 0 + 16 + 4 + 1 + 1 = 36)

    ¿De dónde sale el 7?

    Es . Los 8 viajes son una muestra de todos los que hace el camión, y las distancias se han medido desde la media de esos mismos 8 viajes, que está en su centro; desde la media verdadera del camión saldrían, en promedio, un poco más largas. La demostración de §3 dice cuánto: la suma de cuadrados se queda corta en promedio en una varianza entera, así que se divide entre 7 en vez de entre 8. Las unidades: la varianza está en ; la raíz devuelve L/100 km.

    Qué significa: el camión gasta 33 ± 2,27 L/100 km. Es la cifra que da pandas (.std()); NumPy, por defecto, daría 2,12.

  4. La media es el número que menos se equivoca

    En palabras

    Si representáramos los 8 viajes con otro número , por ejemplo 32, ¿cuánto sumarían los errores al cuadrado? La identidad de §1 lo dice sin repetir la tabla: lo de la media (36) más 8 veces la distancia a la media al cuadrado.

    La cuenta

    ¿De dónde sale el 8?

    Es : al mover el número 1 L/100 km, cada uno de los 8 viajes añade a su error, además de lo que ya tenía (los términos cruzados se cancelan porque las desviaciones suman 0, paso 2). Con sale también 44: la curva es simétrica alrededor de 33, y su mínimo, 36, es la suma de cuadrados del paso 3.

  5. La mediana y el registro de 370

    En palabras

    Ordenamos los 8 valores: 30, 31, 32, 32, 33, 34, 35, 37. Con un número par, la mediana es la media de los dos centrales. Después repetimos con el viaje 5 guardado como 370 (coma perdida): el 370 solo pasa a ser el último de la fila.

    La cuenta

    ¿Por qué la z no pasa de 2,47?

    El valor raro entra en la media y, sobre todo, en la desviación típica con la que se le mide: cuanto más lejos está, más hincha . El máximo posible de con datos es (§2), y el 370 está prácticamente en él. Una regla de «raro si » no lo encontraría nunca con 8 viajes.

    Qué significa: un error de una tecla dobla la media (de 33 a 74,6) y multiplica por 53 la desviación típica. La mediana no se mueve. En un informe automático: validar el rango físico antes de resumir, y publicar media y mediana juntas.

  6. Otra columna: coeficiente de variación y z

    En palabras

    Los mismos viajes tuvieron 12, 25, 8, 15, 40, 10, 18 y 16 minutos de ralentí. Repetimos los pasos 1 a 3 y comparamos las dos columnas sin unidades: el coeficiente de variación (CV, desviación típica entre media) y la del viaje 5.

    La cuenta

    ¿Por qué dividir entre la desviación típica?

    Porque convierte cada columna a su propia regla: «cuántas desviaciones típicas por encima de lo normal». Restar la media lleva el centro a 0 y dividir quita las unidades (L/100 km entre L/100 km, minutos entre minutos). Es lo que hace el escalado de variables antes de un modelo, aunque StandardScaler dividiría entre la versión «÷ 8» (2,12 y 9,66) y daría 1,89 y 2,28.

    Qué significa: el ralentí varía mucho más que el consumo (57 % frente a 6,9 %), y el viaje 5 es más excepcional por su ralentí (2,13 desviaciones típicas) que por su consumo (1,76).

  7. Lo mismo, dato a dato (Welford)

    Con 32, 35 y 30 la media es 97/3 = 32,33 y la suma de cuadrados es : lo mismo que , sin haber guardado los datos. Siguiendo con los cinco viajes restantes, pasa por 13,0, 29,2, 34,0 y 34,86 y acaba en 36 con : la suma de cuadrados del paso 3, y .

    Qué significa: tres números por camión bastan para tener media y desviación típica al día, y dos resúmenes (por ejemplo, lunes a miércoles y jueves a domingo) se juntan con la fórmula de fusión de §5 sin volver a leer nada.

ejemplo.py · reproduce los números de arriba

import numpy as np
from resumen import media, mediana, varianza, desviacion, cv, Welford

x = np.array([32, 35, 30, 33, 37, 31, 34, 32], float)          # L/100 km de 8 viajes
d = x - media(x); print(media(x), d, d.sum(), d**2, (d**2).sum())
print(varianza(x, 0), round(varianza(x, 1), 4), round(desviacion(x, 0), 4), round(desviacion(x, 1), 4))
print([36 + 8 * (33 - c) ** 2 for c in (32, 33, 34)], ((x - 32) ** 2).sum())   # Σ(x − c)² = 36 + 8(33 − c)²
print(mediana(x), round(cv(x) * 100, 2))
y = x.copy(); y[4] = 370                                         # el 37 guardado como 370
print(media(y), mediana(y), round(desviacion(y), 2), round((370 - media(y)) / desviacion(y), 4), round(7 / np.sqrt(8), 4))
r = np.array([12, 25, 8, 15, 40, 10, 18, 16], float)            # minutos de ralentí de los mismos viajes
print(media(r), (r - media(r)).tolist(), ((r - media(r)) ** 2).sum(), round(desviacion(r), 3), round(cv(r) * 100, 1))
print(round((37 - 33) / desviacion(x), 3), round((40 - 18) / desviacion(r), 3))
w = Welford()
for v in x:
    w.add(v); print(w.n, round(w.m, 4), round(w.M2, 4))

Qué cambiaría en un sistema real

  • Validación de rango en la ingesta: un 370 se descarta (o se marca) antes de entrar en ningún resumen.
  • Resúmenes incrementales: por camión y día con Welford, fusionados para la semana o el mes.
  • Consumo ponderado por kilómetros, no media de los L/100 km de cada viaje.
  • Mediana y percentiles aproximados (t-digest) junto a la media, para detectar a la vez errores y camiones raros.
