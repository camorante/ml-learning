§5 · En la práctica

Huecos, valores atípicos y suavizado

  • Sin medida (túnel, paquete perdido): solo se predice. crece con cada paso y la primera medida tendrá mucha ganancia.
  • Medidas a destiempo: con variable se recalculan y en cada paso. Si una medida llega tarde, se reprocesa desde su instante o se usa un filtro con retardo.
  • Gating: se descarta si (por ejemplo 13.8 con y 99.9 %). Si se descartan muchas seguidas, el filtro está divergiendo y hay que reiniciarlo.
  • Suavizado RTS (Rauch-Tung-Striebel): tras filtrar hacia delante, una pasada hacia atrás con combina pasado y futuro:

Es lo que hay que usar para reconstruir rutas ya terminadas (kilometraje, informes). En el túnel de §8, el error máximo baja de 24.5 m a 7 m.

§6 · Más allá

No linealidad y parientes

  • EKF: linealiza y con sus jacobianos en la estimación actual. Es el caso típico con rumbo y velocidad (giros) o con medidas en latitud y longitud.
  • UKF: propaga puntos sigma por las funciones no lineales y recompone media y covarianza. No necesita derivadas y suele ser más preciso que el EKF.
  • Filtro de partículas: posterior no gaussiana o multimodal (map matching entre calles paralelas) a cambio de mucho más cálculo.
  • Relación con Markov: es un modelo oculto de Markov con estado continuo. Predecir y actualizar es el algoritmo forward, y RTS es forward-backward.
  • Relación con los procesos gaussianos: un GP en el tiempo con kernel Matérn (ν = 1/2, 3/2, 5/2) es exactamente un modelo de espacio de estados. El filtro y RTS resuelven esa regresión en en lugar de (Hartikainen y Särkkä, 2010). El modelo de velocidad constante corresponde a una spline cúbica.

§7 · Implementación

Kalman y RTS desde cero

kalman.py · verificado en 30 pasos con 5 sin medida: medias y covarianzas del filtro iguales a condicionar la gaussiana conjunta de toda la trayectoria con las medidas hasta k (10⁻¹¹ en medias; 4·10⁻⁹ en covarianzas, error relativo ~10⁻¹¹), las de RTS iguales a condicionar con todas las medidas (7·10⁻¹²), y el filtro idéntico a filterpy (9·10⁻¹⁶)

import numpy as np

class Kalman:
    """Filtro de Kalman lineal: x_k = F x_{k-1} + B u_k + w,  z_k = H x_k + v,  w ~ N(0, Q), v ~ N(0, R)."""
    def __init__(self, F, H, Q, R, x0, P0, B=None):
        self.F, self.H, self.Q, self.R, self.B = map(np.atleast_2d, (F, H, Q, R, B if B is not None else np.zeros((len(x0), 1))))
        self.x, self.P = np.asarray(x0, float), np.atleast_2d(P0).astype(float)

    def predict(self, u=0.0):
        self.x = self.F @ self.x + (self.B @ np.atleast_1d(u))
        self.P = self.F @ self.P @ self.F.T + self.Q
        return self.x, self.P

    def update(self, z):
        if z is None:                                   # sin medida (túnel): solo predicción
            return self.x, self.P, None
        y = np.atleast_1d(z) - self.H @ self.x          # innovación
        S = self.H @ self.P @ self.H.T + self.R         # su covarianza
        K = np.linalg.solve(S, self.H @ self.P).T       # ganancia K = P Hᵀ S⁻¹ (S simétrica)
        self.x = self.x + K @ y
        I_KH = np.eye(len(self.x)) - K @ self.H
        self.P = I_KH @ self.P @ I_KH.T + K @ self.R @ K.T   # forma de Joseph: P simétrica y definida positiva
        return self.x, self.P, float(y @ np.linalg.solve(S, y))   # NIS: y' S⁻¹ y

    def filter(self, zs, us=None):
        xs, Ps, xp, Pp, nis = [], [], [], [], []
        for k, z in enumerate(zs):
            a, b = self.predict(0.0 if us is None else us[k]); xp.append(a.copy()); Pp.append(b.copy())
            x, P, e = self.update(z); xs.append(x.copy()); Ps.append(P.copy()); nis.append(e)
        return np.array(xs), np.array(Ps), np.array(xp), np.array(Pp), nis

def rts(F, xs, Ps, xp, Pp):
    """Suavizador de Rauch-Tung-Striebel: usa también las medidas futuras (fuera de línea)."""
    xs_s, Ps_s = xs.copy(), Ps.copy()
    for k in range(len(xs) - 2, -1, -1):
        C = Ps[k] @ F.T @ np.linalg.inv(Pp[k + 1])
        xs_s[k] = xs[k] + C @ (xs_s[k + 1] - xp[k + 1])
        Ps_s[k] = Ps[k] + C @ (Ps_s[k + 1] - Pp[k + 1]) @ C.T
    return xs_s, Ps_s

def cv_model(dt, q, r, dims=1):
    """Velocidad constante con aceleración de ruido blanco (q en m²/s³) y GPS de varianza r (m²)."""
    F1 = np.array([[1, dt], [0, 1]])
    Q1 = q * np.array([[dt**3 / 3, dt**2 / 2], [dt**2 / 2, dt]])
    F = np.kron(np.eye(dims), F1); Q = np.kron(np.eye(dims), Q1)
    H = np.kron(np.eye(dims), np.array([[1.0, 0.0]])); R = r * np.eye(dims)
    return F, H, Q, R

§8 · En producción

Con bibliotecas: GPS en 2D con un túnel

gps_kalman.py · salida real en los comentarios (filterpy 1.4.5)

import numpy as np
from filterpy.kalman import KalmanFilter
from filterpy.common import Q_discrete_white_noise
from scipy.linalg import block_diag

rng = np.random.default_rng(7)
dt, T, sigma_gps = 1.0, 600, 5.0                      # GPS a 1 Hz, 10 minutos, error típico 5 m
# trayectoria "real" en un plano: la velocidad cambia con pequeñas aceleraciones aleatorias
acc = rng.normal(0, 0.2, (T, 2))                     # m/s²
vel = np.array([15.0, 4.0]) + np.cumsum(acc * dt, 0)
pos = np.cumsum(vel * dt, 0)
z = pos + rng.normal(0, sigma_gps, (T, 2))
tunel = (300 <= np.arange(T)) & (np.arange(T) < 330)  # 30 s sin GPS

kf = KalmanFilter(dim_x=4, dim_z=2)                   # estado: x, vx, y, vy
kf.F = block_diag(*[np.array([[1, dt], [0, 1]])] * 2)
kf.H = np.array([[1, 0, 0, 0], [0, 0, 1, 0]])
kf.Q = block_diag(*[Q_discrete_white_noise(2, dt, var=0.05)] * 2)
kf.R = np.eye(2) * sigma_gps**2
kf.x = np.array([z[0, 0], 0, z[0, 1], 0]); kf.P = np.diag([25, 400, 25, 400])

mu, cov = [], []
for zi, t in zip(z, tunel):                            # filtro en línea
    kf.predict()
    kf.update(None if t else zi)                       # None: sin medida, solo predicción
    mu.append(kf.x.copy()); cov.append(kf.P.copy())
mu, cov = np.array(mu), np.array(cov)
ms, Ps, _, _ = kf.rts_smoother(mu, cov)               # suavizado fuera de línea

err = lambda est: np.hypot(est[:, 0] - pos[:, 0], est[:, 1] - pos[:, 1])
ok = ~tunel
print(f"GPS crudo:   {np.sqrt(np.mean(err(z[:, [0, 1]])[ok]**2)):.2f} m")   # 7.25 m
print(f"Kalman:      {np.sqrt(np.mean(err(mu[:, [0, 2]])[ok]**2)):.2f} m")  # 3.56 m
print(f"RTS:         {np.sqrt(np.mean(err(ms[:, [0, 2]])[ok]**2)):.2f} m")  # 1.83 m
print(f"en el túnel: Kalman {err(mu[:, [0, 2]])[tunel].max():.1f} m como máximo, RTS {err(ms[:, [0, 2]])[tunel].max():.1f} m")
# en el túnel: Kalman 24.5 m como máximo, RTS 7.0 m
v_err = np.hypot(mu[ok, 1] - vel[ok, 0], mu[ok, 3] - vel[ok, 1])
print(f"velocidad (nunca medida): error medio {v_err[60:].mean():.2f} m/s")    # 0.64 m/s

El filtro en línea reduce el error a la mitad y el suavizado a una cuarta parte, y estima la velocidad con un error de 0.6 m/s sin medirla nunca. Q_discrete_white_noise es la de §1 con , un poco por encima de la real (): un exceso pequeño de es más seguro que un defecto.

§9 · Checklist

Antes de confiar en tu filtro

  • Coordenadas métricas locales (ENU o UTM), no grados de latitud y longitud.
  • real en cada paso; y recalculados si cambia.
  • medida con datos estáticos; ajustada con NIS medio ≈ dimensión de la medida.
  • Gating con y un contador de rechazos seguidos para reiniciar.
  • Forma de Joseph (o raíz cuadrada) y comprobación de que sigue simétrica y positiva.
  • Para análisis posteriores, RTS en lugar del filtro en línea.

§10 · Ejemplo resuelto

¿Dónde está el camión? Cuatro segundos a mano

Un filtro de Kalman de una dimensión, paso a paso: predecir con la velocidad, corregir con el GPS, atravesar un segundo sin señal y volver a corregir.

La situación. Un camión va por una carretera recta a 20 m/s según su velocímetro (CAN bus). Queremos su posición a lo largo de la carretera cada segundo. El GPS da una lectura por segundo con unos 5 m de error. En el segundo 3 pasa bajo un puente y no hay lectura.

Mapa del ejemplo

Cada segundo se hacen dos cosas. Primero predecir: avanzar la posición con la velocidad y aumentar la duda. Después corregir: mezclar la predicción con el GPS según sus dudas. Seguimos 4 segundos, uno de ellos sin GPS.

  1. Los ingredientes: punto de partida y las dos dudas.
  2. Segundo 1: predecir.
  3. Segundo 1: corregir con el GPS.
  4. Segundo 2: otra vuelta.
  5. Segundo 3: bajo el puente, solo predecir.
  6. Segundo 4: la corrección pesa más.
  7. Qué hemos ganado.

  1. Los ingredientes

    En palabras

    Necesitamos dónde creemos que está al empezar y cuánto dudamos de ello. También cuánto puede desviarse el camión de lo previsto en un segundo (la duda del modelo, ) y cuánto se equivoca el GPS (). Las dudas se expresan como varianzas: el error típico al cuadrado.

    La cuenta

    ¿De dónde salen el 25 y el 12.5?

    es el error típico del GPS, 5 m, al cuadrado. Es un valor habitual a cielo abierto, y en un sistema real se mide con un vehículo parado. dice que en un segundo el camión puede apartarse unos m de lo que predice el velocímetro, por frenazos, acelerones o el redondeo de la velocidad. lo elegimos igual que el valor al que el filtro llega solo tras unos segundos, para que las cuentas salgan redondas. Si se empieza con más duda, el filtro converge enseguida a ese mismo valor (§3).

    ¿Por qué varianzas y no errores en metros?

    Porque las varianzas de errores independientes se suman. La duda de "posición anterior + desvío del segundo" es , mientras que los errores en metros no se suman así: , no .

  2. Segundo 1: predecir

    En palabras

    A 20 m/s, en un segundo avanza 20 m. La duda crece: a la que ya teníamos se suma la del segundo que ha pasado.

    La cuenta

    Qué significa: creemos que está en 20 m, con un error típico de m. Ahora la predicción y el GPS son igual de fiables.

  3. Segundo 1: corregir con el GPS

    En palabras

    El GPS dice 26 m: 6 m más de lo esperado (la innovación). La ganancia dice qué parte de esa sorpresa creemos: la duda de la predicción dividida entre la suma de las dos dudas.

    La cuenta

    ¿Por qué la duda baja a la mitad?

    Al combinar dos opiniones independientes igual de fiables, el resultado es el doble de fiable: la varianza se reduce a la mitad. En general, es siempre menor que y que , porque juntar información nunca empeora.

    Qué significa: nos quedamos a mitad de camino entre la predicción (20) y el GPS (26), con un error típico de m. Es menor que los 5 m del GPS solo.

  4. Segundo 2: otra vuelta

    La cuenta

    Qué significa: esta vez el GPS marca menos de lo previsto y la corrección va hacia atrás. Fíjate en que la duda vuelve al mismo valor y la ganancia se repite: el filtro ya está en su régimen estable (el filtro α-β de §3).

  5. Segundo 3: bajo el puente

    En palabras

    No llega lectura. Predecimos como siempre, pero no hay nada con qué corregir, así que la predicción se queda como estimación y la duda no baja.

    La cuenta

    Qué significa: el filtro no se para ni se inventa nada: sigue con la velocidad y admite que ahora duda más (5 m de error típico en lugar de 3.5).

  6. Segundo 4: la corrección pesa más

    La cuenta

    Qué significa: como la predicción venía con más duda (dos segundos acumulados), el filtro le hace más caso al GPS: un 60 % en vez de un 50 %. La duda baja a 15, aún por encima de 12.5, y en un par de segundos volverá a su valor estable.

  7. Qué hemos ganado

    En palabras

    Con solo sumas, restas y una división por segundo, el filtro da una posición más fiable que el GPS (3.5 m frente a 5 m de error típico), sigue funcionando sin señal y dice en cada momento cuánto se puede equivocar.

    ¿Y la velocidad, si el velocímetro se equivoca?

    Aquí la tratamos como una entrada exacta y su error va dentro de . En el modelo completo de §1 la velocidad es parte del estado: el filtro la estima con el GPS y corrige un velocímetro mal calibrado. Ese es el paso natural siguiente.

  • Estado con velocidad (§1) en lugar de fiarse del velocímetro, o ambos: el velocímetro como una segunda medida con su propia .
