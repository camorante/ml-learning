Axioms, the triangle inequality and why it matters

Every norm induces a metric, , invariant under translation. Some widely used "distances" are not metrics: the squared Euclidean (), the cosine distance (it fails the triangle inequality and can't tell proportional vectors apart) and with . They're fine for ranking the neighbors of a point (squared Euclidean gives the same order as Euclidean), but not for what follows.

If an index stores precomputed and you already have a neighbor at distance , every with is discarded. Standardizing doesn't see correlations: if km and hours go together, "going far" counts twice. The Mahalanobis distance uses the inverse of the covariance matrix (covered in a later topic):

It's the Euclidean distance after "whitening" the data (decorrelating and standardizing). With a diagonal it reduces to standardization. It needs many more rows than columns to estimate stably; with few, you regularize (, or the Ledoit-Wolf estimator).

§6 · Efficient computation

The dot-product identity and its pitfalls

The matrix for , can be computed in two ways:

  • Broadcasting: X[:, None, :] - Y[None, :, :] creates an array. It's exact, but it moves numbers through memory: it has to be done in blocks.
  • Matrix product, expanding the square:

The term is a single BLAS call (GEMM), with caching and vectorization. That's how sklearn.metrics.pairwise.euclidean_distances does it. The dot product is the next topic in the collection: the dot product (and its technical version).

The pitfall: cancellation. If the points are far from the origin and close to each other, you subtract two huge, nearly equal numbers. The absolute error in is on the order of , with in float64; with UTM coordinates ( m) that's , comparable to if the points are decimeters apart. You can even get , which is why it's clipped to 0 before the square root.

§7 · From scratch

Norms, distance matrices and neighbors, verified

distancias.py

"""Norms, distances and nearest neighbors, from scratch (numpy only)."""
import numpy as np


def norma(x, p=2.0):
    """Lp norm of a vector (or of each row of a matrix). p=np.inf is the maximum norm."""
    a = np.abs(np.asarray(x, float))
    if p == np.inf:
        return a.max(-1)
    if p == 1:
        return a.sum(-1)
    if p == 2:
        return np.sqrt((a * a).sum(-1))
    return (a ** p).sum(-1) ** (1.0 / p)


def minkowski(x, y, p=2.0, w=None):
    """||x - y||_p, with optional per-component weights: (sum w_i |x_i - y_i|^p)^(1/p)."""
    d = np.asarray(x, float) - np.asarray(y, float)
    if w is not None:
        d = d * np.asarray(w, float) ** (1.0 / p)
    return norma(d, p)


def matriz_distancias(X, Y=None, p=2.0, w=None, bloque=2048):
    """D[i, j] = ||X_i - Y_j||_p by broadcasting, in blocks of rows
    so as not to create a giant (n, m, d) array all at once."""
    X = np.atleast_2d(np.asarray(X, float))
    Y = X if Y is None else np.atleast_2d(np.asarray(Y, float))
    if w is not None:
        s = np.asarray(w, float) ** (1.0 / p)
        X, Y = X * s, Y * s
    D = np.empty((len(X), len(Y)))
    for i in range(0, len(X), bloque):
        D[i:i + bloque] = norma(X[i:i + bloque, None, :] - Y[None, :, :], p)
    return D


def euclidea_rapida(X, Y=None):
    """Euclidean via ||x||² + ||y||² - 2 x·y: one matrix multiplication (fast),
    but with numerical cancellation if the points are far from the origin."""
    X = np.atleast_2d(np.asarray(X, float))
    Y = X if Y is None else np.atleast_2d(np.asarray(Y, float))
    d2 = (X * X).sum(1)[:, None] + (Y * Y).sum(1)[None, :] - 2.0 * X @ Y.T
    return np.sqrt(np.maximum(d2, 0.0))          # rounding can give d² < 0


def estandarizar(X, media=None, desv=None):
    """z = (x - mean) / deviation, by column (population deviation, like StandardScaler)."""
    X = np.asarray(X, float)
    media = X.mean(0) if media is None else media
    desv = X.std(0) if desv is None else desv
    return (X - media) / np.where(desv > 0, desv, 1.0), media, desv


def mahalanobis(X, Y, VI):
    """Mahalanobis distance with VI = inverse of the covariance:
    factor VI = L Lᵀ and use the Euclidean distance on the transformed points x·L."""
    L = np.linalg.cholesky(np.asarray(VI, float))
    return matriz_distancias(np.asarray(X, float) @ L, np.asarray(Y, float) @ L, 2)


def vecinos(Xq, X, k=1, p=2.0, excluir_a_si_mismo=False):
    """Indices and distances of the k points of X closest to each row of Xq."""
    D = matriz_distancias(Xq, X, p)
    if excluir_a_si_mismo:
        np.fill_diagonal(D, np.inf)
    idx = np.argsort(D, axis=1, kind="stable")[:, :k]
    return idx, np.take_along_axis(D, idx, 1)


def knn_predecir(Xtr, ytr, Xq, k=5, p=2.0):
    """Majority vote among the k neighbors (ties: the smallest label)."""
    idx, _ = vecinos(Xq, Xtr, k, p)
    ytr = np.asarray(ytr)
    clases = np.unique(ytr)
    votos = (ytr[idx][:, :, None] == clases[None, None, :]).sum(1)
    return clases[votos.argmax(1)]

import numpy as np
from scipy.spatial.distance import cdist
from sklearn.metrics import pairwise_distances
from sklearn.neighbors import NearestNeighbors, KNeighborsClassifier
from distancias import *

rng = np.random.default_rng(0)
rel = lambda a, b: np.abs(a - b).max() / np.abs(b).max()          # maximum relative error
e = dict(norma=0.0, minkowski=0.0, ponderada=0.0, sklearn=0.0, rapida=0.0, mahalanobis=0.0)
ok_vec = ok_knn = 0
for t in range(200):
    n, m, d = rng.integers(5, 120), rng.integers(5, 120), rng.integers(1, 40)
    X, Y = rng.normal(size=(n, d)) * rng.uniform(0.1, 50), rng.normal(size=(m, d))
    for p in (1, 1.5, 2, 3, np.inf):
        e["norma"] = max(e["norma"], rel(norma(X, p), np.linalg.norm(X, ord=p, axis=1)))
        ref = cdist(X, Y, "chebyshev") if p == np.inf else cdist(X, Y, "minkowski", p=p)
        e["minkowski"] = max(e["minkowski"], rel(matriz_distancias(X, Y, p), ref))
    w = rng.uniform(0.1, 3, d)
    e["ponderada"] = max(e["ponderada"], rel(matriz_distancias(X, Y, 3, w), cdist(X, Y, "minkowski", p=3, w=w)))
    for met, p in (("manhattan", 1), ("euclidean", 2), ("chebyshev", np.inf)):
        e["sklearn"] = max(e["sklearn"], rel(matriz_distancias(X, Y, p), pairwise_distances(X, Y, metric=met)))
    e["rapida"] = max(e["rapida"], rel(euclidea_rapida(X, Y), cdist(X, Y)))
    A = rng.normal(size=(d, d)); VI = np.linalg.inv(A @ A.T + d * np.eye(d))
    e["mahalanobis"] = max(e["mahalanobis"], rel(mahalanobis(X, Y, VI), cdist(X, Y, "mahalanobis", VI=VI)))
    k = int(rng.integers(1, 6))
    i1, _ = vecinos(Y, X, k)
    _, i2 = NearestNeighbors(n_neighbors=k).fit(X).kneighbors(Y)
    ok_vec += np.array_equal(i1, i2)
    ytr = rng.integers(0, 3, n)
    ok_knn += np.array_equal(knn_predecir(X, ytr, Y, k), KNeighborsClassifier(n_neighbors=k).fit(X, ytr).predict(Y))
for k, v in e.items():
    print(f"{k:12s} {v:.1e}")
print("vecinos = NearestNeighbors:", ok_vec, "/ 200 · KNN = KNeighborsClassifier:", ok_knn, "/ 200")

§8 · In the fleet

Scaling changes the neighbor and the accuracy of a KNN

def flota(n=1200, seed=0):
    """Simulated trucks: km/day, stops/day, hours/day, average load (kg) and service type."""
    r = np.random.default_rng(seed)
    tipos = ["urban", "shuttle", "regional", "long-haul"]
    #           (mean, deviation) of km, stops and hours
    par = [((220, 60), (13, 2.0), (8.0, 1.0)), ((240, 60), (4, 1.5), (6.0, 1.0)),
           ((380, 70), (7, 1.5), (8.5, 1.0)), ((650, 80), (2, 1.0), (10.0, 1.0))]

§9 · Checklist

Before using distances in production

  • Numeric columns with known units; categorical ones encoded on purpose (not as arbitrary integers).
  • Scaling fit on training data only (standard, robust or business weights) and saved with the model.
  • Norm chosen on purpose: by default, with extreme values or high dimension, for tolerances.
  • Strong correlations reviewed (regularized Mahalanobis, PCA or dropping redundant columns).
  • Contrast measured: nearest / farthest ratio and distribution of distances on real data.
  • If an index is used (ball tree, VP-tree), the function is a true metric.
  • Coordinates centered before using the dot-product identity; float64 for GPS positions.
  • Bounded memory: distance matrices in blocks, or neighbor search without materializing them.

    (mu) is the mean: the sum divided by 12. (sigma) is the standard deviation: subtract the mean from each value, square it, average and take the square root. We divide by 12 (not by 11) because that's what StandardScaler does; with 11 the numbers would change by 4% and the conclusion would be the same. The 480,366.7 is the sum of the 12 squares + … + .

import numpy as np
from toy import T                                   # the 12 trucks from the simple version

K = T[:, [2, 1]]                                    # km/day and stops/day

print(np.round(media, 3), np.round(desv, 3))        # [368.333 7.708] [200.076 4.25]

for nombre, X in (("km and stops", K), ("scaled", Z)):
    for j in otros:
        print(nombre, j + 1, np.round(X[j] - X[ref], 3),
              [round(float(minkowski(X[ref], X[j], p)), 3) for p in (1, 2, np.inf)])

What would change in a real system

  • Mean and deviation of the whole fleet (and over a long period), not of a dozen trucks.
  • More columns: area, vehicle type, schedule, load. Each one scaled and with a deliberate weight.
  • Hard constraints before measuring: the replacement must have the right driver's license and body type.
  • Business weights if a difference of one stop matters more than one deviation of km.
