PCA

Principal component analysis: rotate the data to look at it from the angle where the differences between cases show the most, and keep only the few directions that matter.

Before we start

The best shadow

Imagine you have to describe a pen using only one photo of its shadow. If you light it from above with the pen standing up, the shadow is a tiny dot: it tells you nothing. If you lay it down, the shadow shows its full length. Same object, but one shadow keeps far more information than the other.

PCA does that with data: if each truck is described by 10 numbers, we can't draw it in 10 dimensions. PCA looks for the angle from which to "cast the shadow" so the trucks end up as spread out as possible, because those differences are the information. The first direction it finds is principal component 1; the next one, perpendicular to it, is component 2; and so on.

Idea 1 of 5

What you gain lengthwise, you lose crosswise

In the toy above, each point has a shadow on the line (blue) and a distance to the line (purple). Rotate the line and watch the bars: the spread of the shadows and the spread of the distances always add up to the same total, like the two legs of Pythagoras' triangle. So looking for the line where the shadows are most spread out is the same as looking for the line that passes closest to all the points. Two ways of saying the same thing.

Idea 3 of 5

Compressing: store 3 numbers instead of 24

A truck's speed profile over the day is 24 numbers (one per hour). But the profiles look alike: some work days in the city, others nights on the highway, others two shifts. PCA finds the "typical shapes" and describes each truck as a mix of a few of them. Move the number of components and watch the reconstruction (blue) get closer to the real profile (orange).

Idea 4 of 5

Units, once again

PCA looks for the direction of greatest spread, and spread is measured in each feature's units. If one goes from 0 to 600 (kilometers) and another from 20 to 45 (liters per 100 km), the first component almost always points at the kilometers just because their numbers are bigger. That's why we almost always standardize first: each feature is measured as "how many times its typical spread" it is away from the average.

Idea 5 of 5

It only knows about straight lines

PCA always projects onto lines and planes. If the data forms a curve (for example, GPS positions along a winding road), the best line lumps together points that are far apart along the curve. To "unroll" curved shapes there are other methods (t-SNE, UMAP), used mostly for drawing.

Look at the two circled points: following the arc they are very far from each other, but their shadows on the line land almost in the same spot. PCA mixes them up.

Putting it all together

The full recipe

  1. Center each feature (subtract its average) and, almost always, standardize it.
  2. Find the direction in which the data is most spread out: component 1.
  3. Find the next one, perpendicular to the previous ones, with the largest spread that's left. And so on.
  4. Check how much information each component captures and keep the first ones until you reach, say, 90%.
  5. Describe each case by its "shadows" on those few components.
  6. Give them names by looking at which features weigh in each one.

In the real world

What is it used for?

Drawing what can't be drawn

Reduce 20 features to 2 to see on a chart which trucks, customers or trips are alike.

Compress and speed up

Fewer columns to store, transmit or feed into another model (KNN, K-means) while losing almost nothing.

Remove noise

The last components are usually noise: rebuilding with only the first ones cleans up the signal.

Spot the odd ones

If a case is poorly rebuilt from the usual components, it doesn't look like the normal ones: a possible sensor fault or anomaly.

To be fair

The good and the not so good

The good

  • Fast, with a single answer (no random starts).
  • Tells you how much information each component keeps.
  • The components don't repeat each other: each one tells something new.
  • Useful as a first step for almost any other model.

The not so good

  • Only finds straight-line relationships.
  • Sensitive to units and to extreme values.
  • The components mix features, and sometimes they're hard to name.
  • "Lots of spread" isn't always "what matters" for predicting something.

Mini glossary

The jargon, in plain English

Dimension
Each feature that describes a case. 6 features = 6 dimensions.
Project
Keep the "shadow" of a point on a line or a plane.
Principal component
A new direction, a mix of the original features, ordered from most to least spread.
Explained variance
What share of all the spread in the data each component captures.
Loadings
How much each original feature weighs in a component.
Standardize
Subtract the average and divide by the standard deviation, so all features weigh the same.
Reconstruction
Going back to the original features from just a few components.
For the curious: the formulas behind it all

You don't need them to understand the idea:

component 1 = the direction (vector of length 1) that maximizes the spread of the points' shadows shadow of a point = sum of (value of each feature × its weight in the component) spread lengthwise + spread crosswise = total spread (Pythagoras)
