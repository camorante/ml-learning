Proyecto completo con redes, para programadores

Un problema de flota de principio a fin: predecir si un camión se averiará en los 30 días siguientes a partir de 28 días de tres sensores, una tabla y dos categorías. El umbral de decisión derivado de los costes; un reparto por camión y por tiempo, y lo que promete una fuga; una red de varias entradas en PyTorch (GRU, embeddings y tabla) con pesos de clase, parada temprana y su corrección de probabilidades; dos referencias, una ablación con tres semillas, el examen con intervalos bootstrap por camión, calibración y análisis de errores. Las métricas y la red, reimplementadas en NumPy y verificadas. Y un resultado honesto: la red no gana a un boosting.

Resumen

  • Calcular una columna con la tabla entera y repartir al azar promete PR-AUC 0,498 y 181,2 € por camión y mes; el examen (camiones nuevos, meses futuros) da 0,378 y 221,7 €. Con el reparto por camión y por tiempo, la validación promete 0,411 y el examen da 0,384.

§2 · Los datos

Una flota simulada con las trampas de una real

3 000 camiones, 3 años de días (uno de historial y dos de fotos), 24 fotos de fin de mes por camión. El riesgo diario de avería depende de la edad, los kilómetros al año, la carga, el modelo, el depósito (dos de montaña), una interacción (el modelo F en la montaña se calienta) y una fragilidad propia de cada camión, oculta, con desviación 1,2 en escala logarítmica. El 75 % de las averías avisan antes en un sensor (de 4 a 35 días): ráfagas de vibración (rodamiento), temperatura que sube (refrigeración) o presión que baja (aceite). Encima hay ruido: vaivén lento AR(1), estación, baches, olas de calor y fallos del sensor de aceite.

datos.py · la simulación, el reparto y las filas

"""Datos del tema 13: una flota simulada de 3 000 camiones durante 2 años, con lecturas diarias de tres sensores del
motor y sus averías. Cada fin de mes (24 «fotos» por camión) se pregunta: ¿se averiará en los próximos 30 días?

Entradas de cada foto:
  · secuencia: los últimos 28 días de tres sensores (vibración en mm/s, temperatura máxima del refrigerante en °C y
    presión de aceite en bar);
  · tabla: edad (años), kilómetros totales (miles), carga media del mes (t), kilómetros del mes (miles) y averías
    del camión en los 12 meses anteriores (solo pasado);
  · categorías: modelo de camión (8) y depósito (10).
Lo que la red no ve: la fragilidad propia de cada camión y si una avería avisó antes en los sensores."""
import os
import numpy as np

N_CAM, MESES, VENT, HOR = 3000, 24, 28, 30           # camiones, fotos por camión, días de secuencia, días de horizonte
HIST = 365                                            # un año de historial antes de la primera foto
DIAS = HIST + VENT + 30 * (MESES - 1) + HOR           # 1 113 días simulados
MODELOS = ["A", "B", "C", "D", "E", "F", "G", "H"]
DEPOS = ["Madrid", "Barcelona", "Valencia", "Sevilla", "Zaragoza", "Bilbao", "Asturias", "León", "Málaga", "Murcia"]
MONTANA = [6, 7]                                      # Asturias y León: puertos de montaña
LARGO = [0, 4, 7, 9]                                  # depósitos de larga distancia (más km al año)
EF_MOD = np.array([0.0, 0.3, -0.2, 0.5, 0.1, -0.3, 0.4, 0.0])   # fragilidad de cada modelo (log del riesgo)
CANALES = ["vibración", "temperatura", "presión de aceite"]
SIG = np.array([0.4, 1.2, 0.15])                       # ruido diario de cada sensor (mm/s, °C, bar)
P_AVISO = 0.75                                         # probabilidad de que una avería avise en los sensores
B0 = -7.36                                             # nivel de riesgo: ≈ 8 % de fotos con avería en 30 días


def simular(seed=13):
    rng = np.random.default_rng(seed)
    n = N_CAM
    mod = rng.choice(8, n, p=[0.16, 0.14, 0.14, 0.12, 0.12, 0.12, 0.10, 0.10])
    dep = rng.integers(0, 10, n)
    edad0 = rng.uniform(0.5, 10, n)
    km_an = np.where(np.isin(dep, LARGO), 140, 75) * rng.normal(1, 0.12, n)          # miles de km al año
    carga = np.clip(rng.normal(18, 3.5, n) + 2 * np.isin(dep, LARGO), 8, 26)        # t
    frag = rng.normal(0, 1.2, n)                                                     # fragilidad propia (oculta)
    km0 = edad0 * km_an * rng.uniform(0.8, 1.2, n)
    t = np.arange(DIAS)
    edad = edad0[:, None] + t / 365
    mont = np.isin(dep, MONTANA)
    inter = 1.0 * ((mod == 5) & mont)                                                 # modelo F en la montaña: se calienta
    eta = (B0 + 0.09 * edad + 0.25 * (km_an[:, None] / 100 - 1) + 0.05 * (carga[:, None] - 18)
           + EF_MOD[mod][:, None] + 0.3 * mont[:, None] + inter[:, None] + frag[:, None])
    h = np.exp(eta)                                                                   # riesgo diario
    # averías: un día con probabilidad h; tras una avería, 15 días sin otra (reparación)
    u = rng.random((n, DIAS))
    fallos = []
    for i in range(n):
        f, ult = [], -99
        for d in np.flatnonzero(u[i] < h[i]):
            if d - ult >= 15:
                f.append(d); ult = d
        fallos.append(f)
    # tipo de avería: 0 rodamiento (vibración), 1 refrigeración (temperatura), 2 aceite (presión)
    sens = np.zeros((n, DIAS, 3))
    nivel = np.c_[rng.normal(4.0, 0.5, n) + 0.15 * mod, rng.normal(88, 1.5, n) + 0.1 * (carga - 18), rng.normal(4.0, 0.2, n)]
    estacion = 2.5 * np.sin(2 * np.pi * (t - 100) / 365)                              # verano más caluroso
    w = np.zeros((n, 3)); deriva = np.zeros((n, DIAS, 3))
    for d in range(DIAS):                                                             # vaivén lento AR(1)
        w = 0.85 * w + rng.normal(0, 0.35, (n, 3)); deriva[:, d] = w
    sens = nivel[:, None, :] + SIG * (deriva + rng.normal(0, 1, (n, DIAS, 3)))
    sens[:, :, 1] += estacion
    # molestias sin avería: baches (vibración), olas de calor (temperatura) y fallos del sensor de aceite
    bache = rng.random((n, DIAS)) < 0.05
    sens[:, :, 0] += bache * rng.uniform(1.5, 3.5, (n, DIAS)) * SIG[0] * 2.5
    calor = rng.random((n, DIAS)) < 0.01
    for k in range(4):
        sens[:, k:, 1] += np.roll(calor, k, 1)[:, k:] * 1.8 * SIG[1] * 1.5
    glitch = rng.random((n, DIAS)) < 0.02
    sens[:, :, 2] -= glitch * rng.uniform(2, 4, (n, DIAS)) * SIG[2]
    info = []                                                                         # (camión, día, tipo, aviso, días de aviso)
    for i in range(n):
        for F in fallos[i]:
            tipo = 1 if (inter[i] and rng.random() < 0.7) else rng.choice(3, p=[0.4, 0.35, 0.25])
            avisa = rng.random() < P_AVISO
            L = int(rng.integers(4, 36)) if avisa else 0
            info.append((i, F, tipo, int(avisa), L))
            if not avisa:
                continue
            a = max(0, F - L)
            prog = (np.arange(a, F) - (F - L) + 1) / L                                # de 0 a 1 hasta la avería
            if tipo == 0:
                sens[i, a:F, 0] += SIG[0] * (1.5 * prog + (rng.random(F - a) < 0.15 + 0.55 * prog) * rng.uniform(2.5, 5, F - a))
            elif tipo == 1:
                sens[i, a:F, 1] += SIG[1] * (2.5 * prog + (rng.random(F - a) < 0.2) * 1.5)
            else:
                sens[i, a:F, 2] -= SIG[2] * 2.8 * prog
    # fotos de fin de mes
    S = HIST + VENT + 30 * np.arange(MESES)                                           # día de cada foto
    previas = np.array([[sum(s - 365 <= F < s for F in fallos[i]) for s in S] for i in range(n)])
    X = np.stack([sens[:, s - VENT:s] for s in S], 1).astype(np.float32)              # (n, 24, 28, 3)
    tab = np.stack([np.stack([edad0 + s / 365, (km0 + km_an * s / 365), carga + rng.normal(0, 1, n),
                              km_an / 12 * rng.normal(1, 0.1, n), previas[:, m]], 1) for m, s in enumerate(S)], 1)  # (n, 24, 5)
    Y = np.zeros((n, MESES), np.int8); VIS = np.full((n, MESES), -1, np.int8); TIPO = np.full((n, MESES), -1, np.int8)
    for (i, F, tipo, avisa, L) in info:
        for m, s in enumerate(S):
            if s <= F < s + HOR and Y[i, m] == 0:
                Y[i, m] = 1; TIPO[i, m] = tipo
                VIS[i, m] = int(avisa and F - L < s)                                   # el aviso ya había empezado
    return dict(X=X, tab=tab.astype(np.float32), mod=mod, dep=dep, Y=Y, VIS=VIS, TIPO=TIPO, frag=frag, ntot=np.array([len(f) for f in fallos]),
                fallos=np.array(info), S=S)


def reparto(seed=7):
    """Por camión (60/20/20) y por tiempo: entrena con los meses 0–15, valida con 16–19 y examina con 20–23."""

    p = rng.permutation(N_CAM)
    return dict(tr=(np.sort(p[:1800]), np.arange(0, 16)), va=(np.sort(p[1800:2400]), np.arange(16, 20)),
                te=(np.sort(p[2400:]), np.arange(20, 24)))

§3 · Reparto

Por camión y por tiempo, y lo que cuesta no hacerlo

El modelo se usará con meses futuros y con camiones que entran en la flota. El reparto lo imita (D1): 1 800 camiones × meses 0–15 para entrenar, 600 × meses 16–19 para validar (parada temprana, número de árboles) y 600 × meses 20–23 para el examen, que se mira una vez. Las celdas fuera de esos bloques no se usan. Y cada columna se calcula con lo que se sabía en la fecha de la foto: las averías de los 12 meses anteriores, nunca las del mes que se predice.

La fuga clásica (Kaufman et al., 2012) es calcular algo con toda la tabla antes de repartir. fuga.py la reproduce: las «averías al año» de cada camión, contadas en los dos años, sustituyen al historial, y las fotos de los 2 400 camiones de entrenamiento y validación se reparten al azar.

§4 · Entradas

Escalado, una copia centrada y rasgos hechos a mano

Medias y desviaciones salen solo del entrenamiento (D7). La secuencia entra como 6 canales × 28 días: los 3 sensores escalados y los mismos menos su media de los 21 primeros días, que quita el nivel propio de cada camión (la desviación entre camiones es comparable al ruido diario). Las referencias reciben 18 resúmenes por ventana (media, desviación, máximo, mínimo, pendiente por mínimos cuadrados y últimos 7 días menos los 21 anteriores, por sensor), las 5 columnas de la tabla y las categorías.

rasgos.py

"""Preparación de las entradas: escalado con las medias del entrenamiento (D7) y rasgos hechos a mano para el modelo de
referencia (6 resúmenes por sensor: media, desviación, máximo, mínimo, pendiente y últimos 7 días menos los 21 de antes)."""
import numpy as np


class Escalador:
    """Resta la media y divide por la desviación, ambas calculadas SOLO con el entrenamiento."""
    def __init__(s, A, ejes):
        s.m, s.d = A.mean(ejes, keepdims=True), A.std(ejes, keepdims=True)

    def __call__(s, A):
        return (A - s.m) / s.d


def a_mano(X):
    """X: (n, 28, 3) → (n, 18) resúmenes por sensor."""
    t = np.arange(X.shape[1]) - (X.shape[1] - 1) / 2
    pend = (X * t[None, :, None]).sum(1) / (t ** 2).sum()                 # pendiente por día (mínimos cuadrados)
    R = [X.mean(1), X.std(1), X.max(1), X.min(1), pend, X[:, -7:].mean(1) - X[:, :-7].mean(1)]
    return np.concatenate(R, 1)


NOMBRES = [f"{r}_{c}" for r in ["media", "desv", "max", "min", "pend", "ult7"] for c in ["vib", "temp", "aceite"]]


def secuencia(X, esc):
    """(n, 28, 3) → (n, 6, 28): los 3 sensores escalados y, además, cada uno menos su media de los 21 primeros días
    (lo que se ha movido respecto a lo normal de ESE camión)."""
    s = esc(X).transpose(0, 2, 1)
    return np.concatenate([s, s - s[:, :, :21].mean(2, keepdims=True)], 1).astype(np.float32)


def preparar(F, esc=None):
    """Entradas de la red: secuencia (n, 6, 28) y tabla (n, 5), escaladas; modelo y depósito como enteros."""
    if esc is None:
        esc = dict(seq=Escalador(F["X"], (0, 1)), tab=Escalador(F["tab"], 0))
    return dict(seq=secuencia(F["X"], esc["seq"]), tab=esc["tab"](F["tab"]).astype(np.float32),
                mod=F["mod"].astype(np.int64), dep=F["dep"].astype(np.int64), y=F["y"]), esc

§5 · La red

Tres ramas y una cabeza

La rama de secuencia es una GRU de 16 unidades (tema 9) cuyo último estado resume los 28 días; el orden importa, porque el aviso, si existe, está al final de la ventana. Modelo y depósito entran por embeddings de dimensión 3 (tema 10); la tabla, escalada. La cabeza es una capa de 16 neuronas ReLU con dropout 0,2 (tema 7) y una salida lineal: un logit. En total, 1 671 parámetros (1 152 en la GRU, 54 en los embeddings y 465 en la cabeza). El entrenamiento usa Adam con tasa 0,001 y lotes de 256 (tema 6) y la pérdida logística ponderada del tema 4,

con parada temprana sobre la misma pérdida en validación (paciencia 12, se recuperan los pesos de la mejor época).

"""La red de varias entradas del tema y su entrenamiento: Adam, pesos de clase y parada temprana con paciencia."""
import copy
import numpy as np
import torch
from torch import nn

torch.set_num_threads(4)


class Red(nn.Module):
    """Rama de secuencia (una GRU de 16 unidades que lee los 28 días: tema 9), embeddings de modelo y depósito
    (tema 10) y la tabla escalada; todo se concatena y pasa por una cabeza densa (tema 3) que da un logit.
    `ramas` elige qué entradas usa (para la ablación); "cnn" cambia la GRU por dos convoluciones 1D con máximo y
    media globales (tema 8); `n_cam` > 0 añade un embedding por camión (la trampa de §2)."""
    def __init__(s, ramas=("seq", "emb", "tab"), n_cam=0):
        super().__init__()
        s.ramas, s.n_cam, d = ramas, n_cam, 0
        if "seq" in ramas:
            s.gru = nn.GRU(6, 16, batch_first=True); d += 16
        if "cnn" in ramas:
            s.c1, s.c2 = nn.Conv1d(6, 8, 5), nn.Conv1d(8, 8, 5); d += 16
        if "emb" in ramas:
            s.e_mod, s.e_dep = nn.Embedding(8, 3), nn.Embedding(10, 3); d += 6
        if "tab" in ramas:
            d += 5
        if n_cam:
            s.e_cam = nn.Embedding(n_cam + 1, 4); d += 4          # fila 0: camión desconocido
        s.h1, s.out, s.drop = nn.Linear(d, 16), nn.Linear(16, 1), nn.Dropout(0.2)

    def partes(s, b):
        P = []
        if "seq" in s.ramas:
            _, hn = s.gru(b["seq"].transpose(1, 2))                # lee (n, 28, 6) día a día
            P.append(hn[0])                                        # estado tras el último día (n, 16)
        if "cnn" in s.ramas:
            h = torch.relu(s.c2(torch.relu(s.c1(b["seq"]))))       # (n, 8, 20)
            P += [h.amax(-1), h.mean(-1)]
        if "emb" in s.ramas:
            P += [s.e_mod(b["mod"]), s.e_dep(b["dep"])]
        if "tab" in s.ramas:
            P.append(b["tab"])
        if s.n_cam:
            P.append(s.e_cam(b["cam"]))
        return torch.cat(P, 1)

    def forward(s, b):
        return s.out(s.drop(torch.relu(s.h1(s.partes(b)))))[:, 0]


def tensores(E, idx=None):
    idx = slice(None) if idx is None else idx
    return {k: torch.as_tensor(v[idx]) for k, v in E.items()}


def logits(m, E, lote=4096):
    m.eval()
    with torch.no_grad():
        return np.concatenate([m(tensores(E, slice(k, k + lote))).numpy() for k in range(0, len(E["y"]), lote)])


def entrenar(Etr, Eva, seed=0, ramas=("seq", "emb", "tab"), n_cam=0, w=None, lr=1e-3, lote=256, epocas=100, paciencia=12):
    """Adam con pérdida logística ponderada: cada avería pesa w (por defecto, sanas/averías del entrenamiento).
    Para cuando la pérdida de validación lleva `paciencia` épocas sin mejorar y devuelve la mejor época."""
    torch.manual_seed(seed)
    y = Etr["y"]
    w = float((1 - y).sum() / y.sum()) if w is None else w
    m = Red(ramas, n_cam)
    opt = torch.optim.Adam(m.parameters(), lr=lr)
    perd = nn.BCEWithLogitsLoss(pos_weight=torch.tensor(w))
    g = torch.Generator().manual_seed(seed + 1)
    T = tensores(Etr)
    pond = lambda z, y: float(perd(torch.as_tensor(z), torch.as_tensor(y)))
    curva, mejor, est = [], (np.inf, 0), None
    for ep in range(1, epocas + 1):
        m.train()
        orden = torch.randperm(len(y), generator=g)
        for k in range(0, len(y), lote):
            j = orden[k:k + lote]
            b = {c: v[j] for c, v in T.items()}
            opt.zero_grad(); perd(m(b), b["y"]).backward(); opt.step()
        ztr, zva = logits(m, Etr), logits(m, Eva)
        curva.append((pond(ztr, y), pond(zva, Eva["y"])))
        if curva[-1][1] < mejor[0]:
            mejor, est = (curva[-1][1], ep), copy.deepcopy(m.state_dict())
        elif ep - mejor[1] >= paciencia:
            break
    m.load_state_dict(est)
    return m, dict(curva=curva, mejor=mejor[1], w=w)


def prob(m, E, w):
    """Probabilidad corregida: el peso w multiplica las probabilidades a favor (odds) por w; se deshace restando ln w."""
    return 1 / (1 + np.exp(-(logits(m, E) - np.log(w))))

"""Modelos de referencia con los 18 rasgos hechos a mano + la tabla (5 columnas) + las categorías: regresión logística (one-hot)
y boosting de árboles (HistGradientBoosting, categorías nativas, nº de árboles elegido con la validación)."""
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.metrics import log_loss
from rasgos import a_mano, Escalador


def matriz_rasgos(F):
    return np.concatenate([a_mano(F["X"]), F["tab"]], 1)


def logistica(Ftr, Fva, Fte):
    A = [matriz_rasgos(F) for F in (Ftr, Fva, Fte)]
    esc = Escalador(A[0], 0)
    oh = lambda F: np.c_[np.eye(8)[F["mod"]], np.eye(10)[F["dep"]]]
    M = [np.c_[esc(a), oh(F)] for a, F in zip(A, (Ftr, Fva, Fte))]
    lr = LogisticRegression(C=1.0, max_iter=5000).fit(M[0], Ftr["y"])
    return [lr.predict_proba(m)[:, 1] for m in M[1:]]


def boosting(Ftr, Fva, Fte, seed=0):
    M = [np.c_[matriz_rasgos(F), F["mod"], F["dep"]] for F in (Ftr, Fva, Fte)]
    gb = HistGradientBoostingClassifier(max_iter=600, learning_rate=0.05, max_leaf_nodes=15, min_samples_leaf=40,
                                        categorical_features=[23, 24], early_stopping=False, random_state=seed).fit(M[0], Ftr["y"])
    pva = list(gb.staged_predict_proba(M[1]))
    k = int(np.argmin([log_loss(Fva["y"], q[:, 1]) for q in pva]))
    pte = list(gb.staged_predict_proba(M[2]))[k]
    return pva[k][:, 1], pte[:, 1], k + 1

"""Desde cero en NumPy: curva precisión-exhaustividad, precisión media (PR-AUC), área ROC, coste en euros, umbral por
costes y bootstrap por camión. check.py los compara con scikit-learn."""
import numpy as np

C_REV, C_AVE = 400.0, 4000.0          # revisión preventiva (mecánico + un día parado) y avería en ruta, en €
UMBRAL = C_REV / C_AVE                # avisar si p · 4 000 > 400 → p > 0,10


def curva_pr(y, p):
    """Recorre los umbrales de mayor a menor (uno por cada valor distinto de p). Devuelve exhaustividad, precisión
    y umbral en cada corte."""
    o = np.argsort(-p, kind="mergesort")
    y, p = np.asarray(y, float)[o], np.asarray(p)[o]
    corte = np.r_[np.flatnonzero(np.diff(p)), len(p) - 1]        # último índice de cada grupo de empates
    tp = np.cumsum(y)[corte]
    fp = corte + 1 - tp
    return tp / y.sum(), tp / (tp + fp), p[corte]


def pr_auc(y, p):
    """Precisión media: suma de (salto de exhaustividad) × (precisión) en cada umbral."""
    r, pr, _ = curva_pr(y, p)
    return float(np.sum(np.diff(np.r_[0, r]) * pr))


def roc_auc(y, p):
    """Probabilidad de que una avería al azar puntúe más que una foto sana al azar (empates cuentan ½), por rangos."""
    y = np.asarray(y).astype(bool)
    o = np.argsort(p, kind="mergesort"); ps = np.asarray(p)[o]
    rango = np.empty(len(p)); i = 0
    while i < len(p):                                            # rango medio en los empates
        j = i
        while j + 1 < len(p) and ps[j + 1] == ps[i]:
            j += 1
        rango[o[i:j + 1]] = (i + j) / 2 + 1; i = j + 1
    n1, n0 = y.sum(), (~y).sum()
    return float((rango[y].sum() - n1 * (n1 + 1) / 2) / (n1 * n0))


def coste(y, p, u=UMBRAL):
    """Coste medio por camión y mes: 400 € por cada aviso y 4 000 € por cada avería sin aviso."""
    a = np.asarray(p) > u
    return float(np.mean(a * C_REV + (~a) * np.asarray(y) * C_AVE))


def matriz(y, p, u=UMBRAL):
    a, y = np.asarray(p) > u, np.asarray(y).astype(bool)
    return dict(vp=int((a & y).sum()), fp=int((a & ~y).sum()), fn=int((~a & y).sum()), vn=int((~a & ~y).sum()))


def bootstrap(cam, y, p, f, B=2000, seed=0):
    """Remuestrea camiones enteros (con sus 4 meses) con reemplazo, B veces, y devuelve f en cada réplica."""
    rng = np.random.default_rng(seed)
    u, inv = np.unique(cam, return_inverse=True)
    grupos = [np.flatnonzero(inv == k) for k in range(len(u))]
    out = np.empty(B)
    for b in range(B):
        idx = np.concatenate([grupos[k] for k in rng.integers(0, len(u), len(u))])
        out[b] = f(y[idx], p[idx])
    return out

def gru_np(x):
    """x: (n, 28, 6). Ecuaciones de PyTorch: puertas r, z y candidata n; h ← (1 − z)·n + z·h."""
    Wi, Wh, bi, bh = W["gru.weight_ih_l0"], W["gru.weight_hh_l0"], W["gru.bias_ih_l0"], W["gru.bias_hh_l0"]
    H = Wh.shape[1]; h = np.zeros((x.shape[0], H))
    for t in range(x.shape[1]):
        gi, gh = x[:, t] @ Wi.T + bi, h @ Wh.T + bh
        r, zz = sig(gi[:, :H] + gh[:, :H]), sig(gi[:, H:2 * H] + gh[:, H:2 * H])
        n = np.tanh(gi[:, 2 * H:] + r * gh[:, 2 * H:])
        h = (1 - zz) * n + zz * h
    return h

§12 · A producción

Lo que hay que montar alrededor del modelo

El modelo es la parte pequeña del sistema (Sculley et al., 2015). Lo que queda:

  • Una tubería única que calcula las entradas igual al entrenar y cada fin de mes: el mismo escalador guardado, la misma ventana, el historial «a fecha».
  • Vigilar las entradas. Distribución de cada sensor y columna (PSI o una prueba de Kolmogórov-Smirnov frente al entrenamiento), huecos y valores imposibles. Para las secuencias, el error de reconstrucción de un autoencoder entrenado con ventanas normales: si su media sube, llegan ventanas que el modelo no ha visto (una caja de telemetría nueva, un firmware).
  • Vigilar las salidas. Número de avisos y riesgo medio cada mes: un salto es la alarma más temprana.
  • Medir el resultado cuando llega, un mes después: coste real frente al previsto, calibración por grupos.
  • Cuidado con el bucle. Los camiones revisados ya no se averían: los datos nuevos tienen menos averías justo donde el modelo acertaba. Hay que registrar la intervención y, si se puede, dejar una pequeña muestra sin intervenir.
  • Reentrenar con plan: cada cuánto, con qué ventana, y el mismo examen (por camión y tiempo) antes de sustituir al modelo en uso.
