# ML learning · Aprender viendo

Explicaciones visuales e interactivas de machine learning, en español (`-es`) e inglés (`-en`).
Abre `index.html` en el navegador: es la puerta de entrada a las tres colecciones y tiene selector de idioma.

- **Serie ML visual** (`serie-ml-visual-es.html` / `visual-ml-series-en.html`): 14 algoritmos.
- **Preparar los datos** (`preparar-los-datos-es.html` / `preparing-the-data-en.html`): 8 temas.
- **Las matemáticas debajo del ML** (`matematicas-del-ml-es.html` / `math-under-ml-en.html`): 16 temas planificados.

Cada tema tiene una página sencilla (con vídeo `*-con-audio-es.mp4` / `*-with-audio-en.mp4`) y una técnica
(`*-tecnico-es.html` / `*-technical-en.html`). Los vídeos se generan con Manim (`*-manim-*.py`) y su banda
sonora con `*-audio-*.py`. Las carpetas `codigo-*` contienen el código Python verificado de las páginas técnicas.
Los vídeos deben estar en la misma carpeta que las páginas.
